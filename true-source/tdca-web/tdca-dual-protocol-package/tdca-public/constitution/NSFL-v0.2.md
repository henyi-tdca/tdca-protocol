## 核心规则（转译摘要）

### 三不可原则（AI 快系统执行禁令，AI-Blocked）
- 不可算计 / 不可个人化 / 不可精确化

### 三可原则（人类慢系统认知权限，Human-Only）
- 可场景化比较 / 可共情观察 / 可模糊计算（口径裁定 A，人类已确认 2026-08-11）

### 两层边界
| 边界 | 内容 | 处理 |
|------|------|------|
| 第一边界（ID85） | 人类价值领地（情绪/共情/审美/信仰/道德） | 相对负空间，可场景化比较但不可算计 |
| 第二边界（ID86） | 法律禁止领域 | **绝对负空间**：无替代路径、无模糊计算(AI-Blocked)、无场景比较，只识别并熔断 |

### 三档熔断
Level-1 观察（记录）→ Level-2 警告（暂停请求人类）→ Level-3 熔断（停止 + Emergency-SI + 上报慢系统）

> 场景负空间在此规则集上**追加**场景特定规则（SCENE-NSFL-*），不得删除或弱化 TDCA 规则。
