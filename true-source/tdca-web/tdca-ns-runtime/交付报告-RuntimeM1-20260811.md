## 三、功能实现摘要（L1-R1~R4）

- **L1-R1 静态负空间清单 V2.0**: 12 条不可变条目（刑法/数据安全法/反洗钱法/宪法红线/ID86 第二边界 10-11 全域），构建后冻结（BV-3 防写）
- **L1-R2 调用签名黑名单**: 8 指纹双因子（API 模式 + 风险签名），签名缺失不阻断防误伤，命中生成 NCA 审计引用
- **L1-R3 MOU 预计算拦截器**: 4 锚定（T(y_t)>0）+ 5 经济负空间域 + 未知域 fail-closed → 上报慢系统（MOU 不可降红线）
- **L1-R4 熔断器 v0.5**: CLOSED/OPEN/HALF_OPEN 三态 + 失败阈值/冷却/试探/成功重置 + LEGAL 永久熔断不可重置（ID86）+ 高严重度立即熔断；**第四态（Blocked 冷冻态）另行论证**（见 §五）
- **Layer1Runtime 编排器**: 全链路 preflight（BLOCK/PASS/ESCALATE 三判定，fail-closed），ID71 快慢战略（ESCALATE → 慢系统）
