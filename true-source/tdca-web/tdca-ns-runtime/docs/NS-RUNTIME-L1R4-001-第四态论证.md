## 一、问题陈述

参考稿 NSFL-ACCEL-REF-001 §3.1 提出熔断器 v0.5 增加 **Blocked 第四态**（冷冻态）：
「SEA 触发异常即进入冷冻态」，声称源自 ID89 Circuit Breaker 扩展。

ID 核验（TDCA-ID-VERIFY-001）结论:
- ID89 权威定义 = **化学热力学原理簇**（AUTHORITY-ECONOMICS.txt:851-855）——「正向化合自发放热」，
  与电路熔断器**无权威关联**；
- 「Circuit Breaker 扩展（第四态）」在权威文本**无出处**——参考稿自创用法；
- 既有熔断器（tdca-fos/fuse_engine.py + 本 M1 v0.5）为 **CLOSED/OPEN/HALF_OPEN 三态**，
  LEGAL 型永久熔断已覆盖「不可重置」语义（ID86）。

## 二、制度依据分析

### 2.1 第四态想解决的缺口

| 缺口 | 三态覆盖情况 | 第四态增量 |
|------|-------------|-----------|
| SEA 连续失败致熔断 | ✅ OPEN + 冷却期 | — |
| SEA 高严重度违规 | ✅ severe → 立即 OPEN | — |
| LEGAL 不可重置 | ✅ 永久 OPEN（ID86） | — |
| **SEA 自我修改/绕过迹象** | ⚠️ 仅当检测到才触发（依赖 Sensor L2-R5） | 冷冻态=「疑似但未证实」的中间态 |

核心增量: 三态是**事件驱动**（失败/严重度计数），第四态是**怀疑驱动**（Sensor 输出
{Warning, Blocked} 中的 Warning 高置信区间）——即「进化的方向趋近负空间但未越线」。

### 2.2 制度对照

| 制度项 | 约束 | 对第四态的影响 |
|--------|------|---------------|
| **三不可原则**（不可算计/不可个人化/不可精确化） | Sensor 不试图理解进化意图 | 第四态判定必须基于**可观察模式**（行为指纹/拓扑距离），非意图推断 |
| **ID71 快慢战略** | 快系统 99.9% 确定性操作 | 第四态属确定性规则可表达的「边界悬置」——可入快系统，但**触发后必须转慢系统** |
| **ID90 最小化合** | 每个加速决策前书面证明为何物理叠加不够 | 需证明三态 + 静态清单/黑名单/MOU 预计算不足以覆盖该缺口 |
| **F-4 硬宪法不可 OTA** | 升级权保留人类 | 第四态的引入属于**规则语义变更**，须人类裁决（本论证即为前置） |
| **ID89 化学热力学**（权威语义） | 正向化合自发放热 | 支持「边界趋近 → 系统应激」的**防御性激活**隐喻（非电路语义），但仅为类比，非语义来源 |

### 2.3 结论性判断

1. **「Circuit Breaker 扩展」名称不采用**——ID89 无此权威语义，直接引用即违规；
2. 缺口真实存在（怀疑驱动中间态），但**可通过既有机制近似覆盖**:
   - Sensor Warning 高置信 → 映射为既有 `severe=True`（立即熔断 + 上报慢系统）；
   - 或映射为 MOU 预计算 fail-closed（行为域无锚定 → ESCALATE）；
   - 物理叠加已覆盖「疑似边界」情形的最低防护（ID90 满足）。
3. **第四态的实现价值 = 状态持久化区分**（Warning 累积 vs 已证实违规），
   属 **L2-R5 Sensor 输出规格的延伸**（Runtime M2 范围），非 Layer 1 紧急窗口必需。

## 三、建议处置（供人类裁决）

| 选项 | 内容 | 建议 |
|------|------|------|
| **A（推荐）** | L1-R4 保持三态；第四态**不实现**；Sensor Warning 高置信 → 复用 severe 熔断 + 慢系统上报；本论证归档为 L2-R5 输入 | ✅ 最小化合（ID90）+ 不引用自创 ID89 + M1 紧急窗口聚焦 |
| B | 引入「WARNING 计数态」（OPEN 前置子态，非第四态命名） | 仍属规则语义变更，须人类裁决后实现；命名须避开 ID89 声称 |
| C | 对齐 CCP T6（SUSPEND 档位作中间态） | DCD 已明确「不简单对齐 CCP T6」——不采纳 |

## 四、M1 落实

- 熔断器 v0.5 实现为 **CLOSED/OPEN/HALF_OPEN 三态**（tdca-ns-runtime/ns_runtime/breaker_v05.py）；
- LEGAL 型永久熔断 + 自动上报慢系统（ID86 + ID71）已实现；
- `BreakerState` 枚举中以注释标注「BLOCKED 第四态另行论证后实现」；
- 本论证结论（建议 A）**待人类裁决**——裁决后如需第四态，走 DCD 变更或并入 Runtime M2（L2-R5 Sensor 规格）。
