## 三、功能实现摘要（C1-C4）

- **C1 词法/语法/语义**: NSFLLexer（BNF token 流，含位置/字符串/负数/语义注释）→ NSFLParser（递归下降 → NSFLDeclaration AST）→ SemanticAnalyzer（NS-001~005: 未知类型 fail-closed/运算符-类型匹配/layer 一致/parameter 预检）
- **C2 ⊗⊘⊙ 执行语义**: FuseDirective（NS_Operator + CCP T6 档位 + Soft/Hard/Atomic 分级）——⊗ 绝对禁止（LEGAL→PERMANENT_BAN/ATOMIC，alt=∅）、⊘ 条件限制（LIMIT_MAX/MIN/EQ）、⊙ 场景化（RESTRICT_TIER + 域标签）
- **C3 schema 校验**: NSFLRule 对齐 D-2 schema §四（rule_id 注入防护/LEGAL 五底线 NS-010~013/severity 越级 NS-014/Decimal 有限非负）
- **C4 字节码/IR**: NS-Bytecode 指令序列（NSFL_DECL/NS_OP/NS_TIER/NS_ACT/NS_PARAM/NS_ALT/NS_SRC）+ NSFLIR（对齐 CompileStatus OK/PARTIAL/FAILED）+ 确定性输出（BV-3 可验证）
