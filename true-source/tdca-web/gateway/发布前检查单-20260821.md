## ③+ 目标机环境自检（发布前跑一句，防两处翻车）

```bash
cd gateway && python -c "
import os
assert os.environ.get('TDCA_GATEWAY_AUTH') == '1', 'AUTH 未显式设 1'
assert not os.environ.get('TDCA_FOUNDER_PASSWORD'), 'FOUNDER_PASSWORD 有残留值'
_t = os.environ.get('TDCA_GATEWAY_TOKEN', '').strip()
assert _t not in ('', 'TDCA-CRT-demo-2026', 'demo-2026'), 'TOKEN 未设置或仍是 demo 值（fail-closed 防缺省）'
print('env OK')"
```

> 说明：种子代码对空串按 falsy 处理（空串不会当真密码），但平台面板的历史遗留值（含空串）一律清掉最干净；TOKEN 是降级通道专用，公开发布必须换新随机串。**防缺省**：代码侧 `auth.py` 已 fail-closed——`TDCA_GATEWAY_TOKEN` 未设/为空时 CRT 降级通道整体关闭（任何值都过不了），但上面的断言仍要求显式设新随机串，双保险；归一化后裸值 `demo-2026` 与带前缀形式等价，一并拦截。
