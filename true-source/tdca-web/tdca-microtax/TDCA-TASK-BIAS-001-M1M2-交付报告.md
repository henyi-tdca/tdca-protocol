## 三、端到端验证（用户例子：跨场景偏态互补匹配）

```
1. 偏态: 我(文旅)=+0.5 偏买 | 你(农产品)=−0.5 偏卖 | seller-X(文旅)=−0.67 偏卖
2. 你进入文旅场景的匹配排序:
     me        互补 True  preferred  互补度 −0.25   ← 优先（你倾向找我配置）
     seller-X  互补 False same_side  互补度 +0.33   ← 同向（推销你不需要的，排除）
3. 结论: 你倾向找我配置（偏态互补），而非 seller-X（同向偏卖推销）——与您的语义一致
```

**闭环达成**: `场景权重细分（买/卖边）→ 偏态（偏买/偏卖/均衡）→ 跨场景配置决策（互补匹配优先，同向排除）`
