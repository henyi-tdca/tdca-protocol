## 三、领域一端到端演示（5 笔 Skill 调用 × 1000 元）

```
1. 聚合申报: BATCH-{ts} | 笔数 5 | Σ税 137.50 | 零漂移 True（逐笔计算不省略）
2. 逐笔预缴: 5 笔 PREPAID | 账本事件 5 | 已预缴 137.50
3. 账本: 余额汇总 137.50 = MOU 聚合 137.50（全链路一致）
```

**闭环**: `小散高频微交付 → 批量计税（逐笔）→ 聚合申报（Σ=Σ单笔）→ 逐笔预缴 → 实时账本（事件溯源）`

## 四、纪律落实

- **A-7 逐笔计算不省略**: 聚合申报前逐笔计税（`details` 明细可追溯），Σ聚合 = Σ单笔
- **ID80 审计 O(n)**: 账本只存事件流（不存中间态），任意时刻状态 = fold(事件流)
- **BV-3**: freeze 后禁止追加（测试断言）
- **ID92 模拟态**: 全链路 simulated 标注（D-011）
- **裁决② 三池分流**: 未引入——税收去向 = 预缴托管归集（账本 total_tax_settled 语义）
