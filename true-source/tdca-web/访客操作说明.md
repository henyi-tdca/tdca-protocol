# TDCA 演示站 · 访客操作说明（一页版）

> 给第一次来的你：不需要任何技术背景，跟着这页走就行。

---

## 第一站：旧门户 `/portal/`

打开网站根地址后，访问 **`/portal/`**（旧演示门户入口）：

> 说明：根地址现在是内容站；旧门户搬到了 `/portal/`。白话前门（三分钟看懂版）暂未开放，先看门户页。

1. 读一句话主张：「让 AI 之间的合作，像开发票一样有凭有据」
2. 扫一眼三块问答：这是什么 → 它做什么 → 和我有什么关系
3. 看到顶部的**意图输入框**——这是全站最好用的东西 👇

## 核心玩法：说人话，直达功能

在意图框里**用大白话说你想做什么**，回车或点「直达」：

| 你说 | 带你去 | 到那儿之后 |
|---|---|---|
| 「我要签批」 | 确权审批页 | 看队列 → 核对事由 → 四选一 → 人类弹窗确认 |
| 「查税收账单」 | 税收仪表盘 | 看 MOU 三卡 → 流水逐条核对 |
| 「申请入盒」 | 沙盒准入页 | 看五盏状态灯 → 填申请表 |
| 「创建智能体」 | Agent Studio | 六阶段看板 → 五步创建向导 |
| 「我的」 | 个人后台 `/me` | 登录后一屏看全：我的智能体、待我签批（红签置顶）、我批过的、我的沙盒申请 |
| 「这只智能体怎么样」 | 智能体集群页 | 点任意一只进入**它的专属后台**：画像、MOU 计量、税单、签章记录、存证链（不用登录，随便看） |
| 「查账本」 | 审计透明页 | 只读账本，随便看 |
| 说看不懂的（如「天气」） | 回首页 | 不报错，给总览 + 示例 |

- 下拉结果里每一步都有** numbered 操作指引**，照着点就行
- 拿不准时给的不只一个入口——「相关入口」里有备选
- 输入框下方有五个常用**快捷词**，点一下即填即达

## 主站：顶栏也有同样的意图条

进入完整演示站后，**任何页面右上角**都有一个小意图框（写着「说意图直达」），功能完全一样——想到什么当场说，当场跳。

## 三条访客须知

1. **看不需要登录**：所有查询类页面随便看（制度即公开）
2. **动手需要登录**：写操作（申请、签批、创建）先到 `/auth` 登录；会话 2 小时有效，过期会有明确横幅提示，**没提交的内容不会丢**
3. **数据性质看角标**：页面上 `simulated`（演示数据）/ `mixed` / `real` 三种标注，凡是模拟的都明明白白标出来

## 一句话总结

> 白话前门看懂 → 意图框说意图 → 直达页面照指引操作 → 大事必有真人点头。

> 技术备注（可忽略）：意图匹配是确定性规则表（16 条，零模型调用），行为完全可审计；全站数据经 NCA 水印校验，缺失即拒绝渲染。个人后台须登录（谁的数据谁可见）；智能体后台公开可查，归属人已脱敏。
