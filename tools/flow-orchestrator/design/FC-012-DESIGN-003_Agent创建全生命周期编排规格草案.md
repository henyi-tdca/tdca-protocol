## 三、新增 Phase 定义（草案）

### 3.1 P5 认证（Agent Certification）
- **目标**：科目一自动测试 + 科目二人工审查通过，形成认证结论
- **输入**：CCE 报告 + 九类测试结果 + 申请材料包
- **事件**：`AUTO_PASS`（科目一通过）→ `HUMAN_APPROVE`（委员会通过）→ 进入 P6
- **熔断**：负空间熔断率 <100% → FUSE；委员会拒绝 → TERMINATED（6 个月后可重申请）
- **NCA-5**：测试报告哈希 + 审查意见书（含人类签名）

### 3.2 P6 颁发（CRB Badge Issuance）
- **目标**：颁发配置权标识（CRB-YYYY-000001）并上链
- **输入**：认证结论 + 六协议哈希（acrp/nsfl/utility_function/mou_contract/fast_slow_config/nca_config）
- **事件**：`ISSUE`（上链确认）→ 进入 P7
- **熔断**：哈希不一致 / 上链失败 → FUSE（ROLLBACK 至 P5）
- **NCA-6**：badge 快照 + tx_hash + notary 节点
