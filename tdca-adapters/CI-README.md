# tdca-adapters CI 门禁说明

**公开包**（清单见 workflow 顶部声明）的变更由 `.github/workflows/adapters-ci.yml` 自动门禁：

1. **语法校验** — 公开包全量 Python 源文件过语法编译检查
2. **公开件终扫** — 零命中六类：内部编号 / 本机路径 / 内部角色名 / 敏感资源类字样 / 内部目录名 / 编译缓存产物
3. **内部路径注入** — 运行时路径不得引用内部项目目录
4. **无编译缓存** — 本目录全树不得含 Python 编译缓存与测试缓存产物

> 门禁的具体判定词表以 workflow 内定义为准。本目录部分子件为内部台账或早期批次，不在「公开件终扫」范围内，其合规性另行评估。
> 公开件纪律：零内部标识、Apache-2.0、模拟态声明保留（如适用）。
