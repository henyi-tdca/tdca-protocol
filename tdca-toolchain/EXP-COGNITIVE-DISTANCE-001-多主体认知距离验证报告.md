## 二、权威设计依据（实现对齐源）

| 权威定义 | 内容 | 实现对应 |
|---------|------|---------|
| 定义 3.36（认知距离函数） | d_cognitive(a,b) = inf{Length(γ) \| γ 连接 a,b 的认知路径} | `cognitive_distance()`——加权语义距离（非简单欧氏，AUTHORITY-ECONOMICS:1096） |
| 命题 3.10（不对称性） | d(a,b) ≠ d(b,a)——认知势差：高认知理解低认知易（短），反之难（长） | 认知势差惩罚项（level_a < level_b → 距离放大） |
| 定义 3.37（对齐难度） | Difficulty_align(a,b) = exp(−d_cognitive) | `difficulty_ab = exp(-d_ab)` |
| NIA-MACM PHASE-2 | 交换 cognitive_state_vectors → 计算 cognitive_distance(S₁,S₂) → >阈值进入协商协议 | `negotiation_required()`（COMPATIBILITY_THRESHOLD=0.35） |
| ID60 不对称对齐原理 | 智能即不对称对齐能力；对称对齐不可能且有害 | 只定位差异与对齐难度，不消除差异 |

## 三、实现交付

**`tdca-toolchain/tdca_cognitive_distance.py`**（CognitiveDistanceCalculator）:
- `cognitive_distance(s_a, s_b)` / `cognitive_distance_ba()`——有向认知距离（五维加权欧氏 + 认知势差惩罚）
- `measure_pair()`——单对评测（不对称性 + 优势方 + 双向对齐难度）
- `evaluate_event(event, states)`——**多主体不对称对齐评测**（核心）: 距离矩阵 + 不对称对 + 不对称比率 + 对齐难度矩阵 + 最易/最难对齐对
- `negotiation_required()`——NIA-MACM PHASE-2 协商触发
- `validate()`——自证机制（自身距离 0 / 自身对齐难度 1 / 难度 ∈ (0,1]）

**测试**: `tdca-toolchain/tests/test_cognitive_distance.py`（17 用例）

## 五、关键数学发现

1. **不对称有向性（命题 3.10 实证）**: 3 主体认知互异 → 6 有向对全部不对称；
   最难对齐对是 (M1→L1) 而非直觉的 (H1→L1)——因势差惩罚率与基础距离的联合效应，
   低认知端向更高认知理解均困难（正确反映认知势差）
2. **加权语义距离**（非欧氏）: SC（安全合规）权重 0.30 > A（感知）0.15——制度对齐核心
   维优先，符合 AUTHORITY-ECONOMICS:1096「非简单欧氏，含制度约束/场景权重/能力差异」
3. **对齐难度指数衰减**（定义 3.37）: d→∞ 难度→0（完全不可对齐）、d→0 难度→1（完全可对齐）
