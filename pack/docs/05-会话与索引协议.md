# 05 · 会话与索引协议（SI）

> TDCA-PACK-001-DOC-05 | 依据方法论 V1.1 第八章（MEMO-022）
> 定义：三层会话拓扑 / SI 命名 / 加载协议 / 分裂触发器 / 上下文预算。

---

## 1. 三层会话拓扑

| 层 | 体积 | 内容 | 生命周期 | 拓扑映射 |
|----|------|------|---------|---------|
| L0 宪法层 | < 15%（~150k token） | 活宪法版本号 + Δ 修正案清单 + 索引链头 | 跨会话持久，永不压缩 | H-H 制度共识层 |
| L1 任务层 | 15%-60%（~150k-600k） | 当前 FC-ID 六要素 + 上游审查摘要 + 跨 FC 依赖索引 | 单 FC 周期，完成即归档 NCA | H-M 协议编译层 |
| L2 执行层 | < 20%（~200k） | 当前代码生成目标函数 + 约束矩阵 + L0/L1 索引指针 | 单次生成周期，输出即释放 | M-L / L-L 执行交付层 |

## 2. SI 文件命名规范

```
TDCA-SI-{YYYYMMDD}-{SEQUENCE}-{LAYER}-{HASH}.nca
```

| 示例 | 含义 |
|------|------|
| TDCA-SI-20260804-000-L0-a7f3e2.nca | 宪法层索引（基线） |
| TDCA-SI-20260808-002-L1-997d46.nca | 任务层索引 |
| TDCA-SI-20260804-003-L2-2e8f5a.nca | 执行层索引（代码生成完成） |
| TDCA-SI-20260804-003-PRE-1c8d3e.nca | 预索引（60% 预警区生成） |

## 3. 新会话加载协议（四步）

**第一步：宪法层加载（L0）**
- 读取 `TDCA-SI-{DATE}-000-L0-{HASH}.nca`
- 仅加载 `constitutional_digest` 的 `version` 和 `delta_items`
- 禁止携带完整宪法全文（L0 体积 < 150k）

**第二步：任务层加载（L1）**
- 加载 `task_digest.six_elements` 哈希摘要
- 加载 `decision_points` 全部人类签批记录
- 加载 `review_chain` 未关闭 REV 项
- 加载 `cross_session_deps` 中 `bond_type=strong` 依赖
- **禁止加载** `bond_type=weak` 的并行任务

**第三步：执行层初始化（L2）**
- 目标函数 ← task_digest；约束矩阵 ← constitutional_digest；负空间规则 ← nsfl_triggers
- 新建审计轨迹 `TDCA-NCA-{NEW_DATE}-{NEW_SEQ}`

**第四步：完整性校验（6/6 强制）**
1. 索引链哈希连续性
2. 宪法版本兼容性（差距 ≤ 2 小版本）
3. 决策点人类签批完整性
4. 负空间规则时效性
5. 审查链闭合性
6. MOU 预算可用性

> 任一未通过 → 触发负空间熔断，停止执行并上报人类。

## 4. 会话分裂触发器（按上下文使用率）

| 使用率 | 状态 | 动作 |
|--------|------|------|
| < 60% | 🟢 安全区 | 正常执行 |
| 60%-70% | 🟡 预警区 | 生成 Pre-SI（`TDCA-SI-{date}-{seq}-PRE.nca`），准备分裂 |
| 70%-75% | 🟠 临界区 | 强制分裂：①暂停新请求 ②归档当前 L1 任务为 NCA ③生成正式 SI ④人类签批「会话分裂授权」 |
| > 75% | 🔴 紧急区 | 负空间熔断：①立即停止 ②生成 Emergency-SI（仅含决策点）③强制开新会话加载 Emergency-SI + L0-SI ④**上报人类/慢系统网关**（附 Emergency-SI 作为证据基础，含 human_signatory 介入字段——ID71 快系统为慢系统预留异常通道） |

## 5. 上下文预算分配

| 层级 | 预算占比 | 预算 token | 压缩策略 |
|------|---------|-----------|---------|
| L0 宪法层 | 15% | ~150k | 永不压缩 |
| L1 任务层 | 45% | ~450k | 优先保留 |
| L2 执行缓冲 | 30% | ~300k | 动态释放 |
| 安全冗余 | 10% | ~100k | 紧急保留（负空间熔断器 + 应急归档） |

> 总预算控制在 90% 以内，保留 10% 安全冗余。
