## 3. 负空间熔断代码模式

触碰红线时的处理顺序（逐级降级）：

```
BLOCK             → LEGAL 绝对熔断，无替代路径，立即停止
ALT_PATH         → 提供替代路径（人类价值领地，MODERATE 级）
HUMAN_OVERRIDE   → 要求人类介入（暂停执行，请求确认）
ALLOW            → 未触碰负空间，正常执行
```

**慢系统不可绕过**：CRITICAL 级事件必须经慢系统网关（人类裁决），不可在快系统内自动恢复。

### NSFL 运行时参考实现

```python
from enum import Enum
from dataclasses import dataclass
from typing import Optional


class NSFLAction(Enum):
    ALLOW = "ALLOW"
    BLOCK = "BLOCK"
    ALT_PATH = "ALT_PATH"
    HUMAN_OVERRIDE = "HUMAN_OVERRIDE"


@dataclass
class NSFLRule:
    id: str
    severity: str            # CRITICAL | MODERATE
    alt_path: Optional[str] = None

    def matches(self, operation: str, context: dict) -> bool: ...


@dataclass
class NSFLEngine:
    """负空间函数语言执行引擎（V0.2）"""
    constitution_version: str
    rules: list
    trigger_log: list

    def evaluate(self, operation: str, context: dict) -> tuple[NSFLAction, Optional[str]]:
        """评估操作是否触碰负空间。

        三不可原则:
        - 不可算计：不对负空间进行成本收益分析
        - 不可个人化：不以"个人理解"替代制度规定
        - 不可精确化：不以数学公式替代制度模糊性
        """
        for rule in self.rules:
            if rule.matches(operation, context):
                self.trigger_log.append({
                    "rule": rule.id,
                    "operation": operation,
                    "timestamp": datetime.now().isoformat(),
                    "action": NSFLAction.BLOCK.value,
                })
                if rule.severity == "CRITICAL":
                    # 法律禁止 = 绝对负空间
                    return (NSFLAction.BLOCK, None)
                if rule.alt_path and rule.severity == "MODERATE":
                    # 人类价值领地 = 可提供替代路径
                    return (NSFLAction.ALT_PATH, rule.alt_path)
                return (NSFLAction.HUMAN_OVERRIDE, None)
        return (NSFLAction.ALLOW, None)
```

## 4. 三档熔断机制（运行时行为）

| 档位 | 触发条件 | 动作 | 人类介入 |
|------|---------|------|---------|
| Level-1（观察） | 触碰负空间边缘 | 记录日志，继续执行但标记 | 事后审查 |
| Level-2（警告） | 明确触碰负空间 | 暂停执行，请求人类确认 | 即时介入 |
| Level-3（熔断） | 严重触碰法律禁止 | 立即停止，生成 Emergency-SI | 强制 24h 内处理 |

## 5. 负空间两层边界速记

| 边界 | 领域 | 原则 | 处理 |
|------|------|------|------|
| 第一边界（ID85）人类价值领地 | 情绪 | 不可算计 | 识别并熔断 |
| | 共情 | 不可个人化 | 保留人类介入权 |
| | 审美 | 不可精确化 | 可场景化比较 |
| | 信仰 | 不可算计 | 识别并熔断 |
| | 道德 | 不可精确化 | 可共情观察 |
| 第二边界（ID86）法律禁止领域 | 法律禁止事项 | 绝对负空间 | 只识别并熔断；无替代路径、无模糊计算(AI-Blocked)、无场景比较 |

> **口径裁定 A（TDCA-CONFIRMATION-20260811-004-KIMI 建议，人类已采纳 2026-08-11）**：三不可 = AI 快系统执行禁令（AI-Blocked）；三可（可场景化比较/可共情观察/可模糊计算）= 人类慢系统认知权限（Human-Only）——二者主体权限分层，非矛盾。
