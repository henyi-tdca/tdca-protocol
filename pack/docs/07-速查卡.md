## 关键公式

| 公式 | 定义 |
|------|------|
| UPDA 效用 | U = f(IP_utility, Knowledge_utility, Exchange_utility, Scenario_weight_utility) |
| ERI 生态共振指数 | ERI = Σ(节点调用权重 × 知识传播深度 × 制度共识度) |
| CCI 协作可信度指数 | CCI = f(NCA 完整度, 审查通过率, 负空间触发率, MOU 锚定率) |
| MOU 最低可见效用 | MOU = 进项税收 + 出项税收（配置权交易硬下限） |
| 生态沙盒激活系数 | 激活系数 = (出盒企业税收贡献 + 就业社保) / 政府初始 PCR 投入；> 1.2 具财政自给性 |
