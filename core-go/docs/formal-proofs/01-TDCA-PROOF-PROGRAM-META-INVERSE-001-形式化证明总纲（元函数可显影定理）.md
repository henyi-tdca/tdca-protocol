## 一、主定理陈述（元函数可显影定理）

**设定**。TDCA 元函数 Φ : D ⇀ R 为部分、确定、可计算映射：
- 输入域 D = 六要素声明 × 配置权声明 × 场景上下文 × 输入数据；
- 输出域 R = NCA 链段 × MOU 计量段 × 产出 × NSFL 状态；
- 定义域守卫：dom(Φ) = { x | C₁₆(x) ∧ ¬NSFL-trigger(x) }（部分性来自 M-5）；
- 模型假设：确定性（同输入同输出）、记录完备性（NCA 含重算所需全部要素）、
  重算可行性（Verify 可执行）——以上沿用 AXIOM6-PROOF §五 的排除条款。

**定理（四段式）**：
1. **【基例 M-0/M-1/M-2】** 单一场景限制 Φ₀ 存在**可计算反射广义逆** G₀：
   Φ₀∘G₀∘Φ₀ = Φ₀，G₀∘Φ₀∘G₀ = G₀，且 ∀r∈Im(Φ₀): Φ₀(G₀(r)) = r（截面性）；
2. **【归纳 M-3】** 若 ID-96 成立且 MOU 满足 ε-可加性，则任意嵌套深度 n，
   化合系统 Φⁿ 存在可计算反射广义逆 Gⁿ，且五可条件在 ⊗ 下保持；
3. **【等价 M-4】** (2) ⟺ 五可在任意嵌套深度成立 ⟺ 层内（L0–L2）规模可持续；
4. **【不动点 M-6】** 三锚映射（e-CNY 结算 s / MOU 计量 m / 版权链确权 c）
   与 ⊗ 交换：s(Φ₁⊗Φ₂) = s(Φ₁)⊗s(Φ₂)，m、c 同理（接口良定义；外部依赖声明）。

**诚实边界**：Φ 多对一，真逆不存在，本纲领不追求；
(3) 的 L4 宏观治理层为 conditional 扩展，不绑入主定理；
(4) 受 e-CNY/税收/版权链外部接口时间表制约，不承诺日期。

## 完成条件（分层）

**纲领完成条件（三支合取）** = **支一（正空间可信：登记完备无偷渡）** ∧ **支二（负空间可信：无计算通道可绕熔断）** ∧ **支三（沙盒可信：无叙事不经数据升入正空间）**。

其中 **支一、支二** 由本纲领命题承载：

- **支一 · 正空间可信** —— `M-5`（**部分性与负空间**：定义域守卫）＋ `M-7`（`C₁₆` 一致性与定义域非空）；
- **支二 · 负空间可信** —— `M-5` 之「**NSFL 不可逾越**（熔断是映射行为，不是事后标注）」；

⭐ **支三（沙盒可信）显式声明留在制度与业务层** —— ⛔ **不作为本纲领的形式化命题**；其判定依 **沙盒实验**与**数据裁决**，**不以形式化名义使用**。

⚠️ **本条仅界定完成条件的构成与边界**：⛔ 不改 `M-0`~`M-7` 任何命题；⛔ 不改 §一「诚实边界」；⛔ 主定理「兼容条件版 ＋ `conditional`」形态**不变**。

## 二、命题体系（七命题，映射到既有开放问题）

### M-0 基例可审计性（= A-1 强化，Tier A 候选）
- **陈述**：Φ₀ 确定且 NCA 完备 ⟹ 重算验证器 Verify 满足完备性
  (∀x∈dom, Verify(Φ₀(x)) = true)。
- **策略**：构造性——Verify := 从 NCA 记录重算并比对；完备性由确定性一步推出。
- **状态**：Go 断言级已证（A-1，9 断言全 PASS）；剩余工作 = Lean 4 移植（P-1）。

### M-1 可靠性（Soundness，Tier B→A 候选）
- **陈述**：Verify(r) = true ⟹ r ∈ Im(Φ₀) ∧ Φ₀(extract(r)) = r。
- **策略**：由记录完备性，extract 从 NCA 取出重构输入；Verify 通过 ⟹
  重构输入在 dom 内且重放产出等于 r。
- **关键引理**：extract ∘ encode = id on dom（编码-解码互逆，由 schema 保证）。

### M-2 反射广义逆存在（Tier B→A 候选）
- **陈述**：∃ 可计算 G₀ : R → D，Φ₀G₀Φ₀ = Φ₀ 且 G₀Φ₀G₀ = G₀。
- **策略**：像集上取截面 g（M-1 给出）；像集外定义 G₀(r) := g(proj(r)) 或
  回退到规范代表元 x*；直接验证两条公理（von Neumann 正则性）。
- **难度**：低（代数验证，无分析）。

### M-5 部分性与负空间（= P-3 的 NSFL 半，★★）
- **陈述**：Φ 为部分映射，守卫 = C₁₆ ∧ ¬NSFL-trigger；BLOCKED 产出
  r⊥ 的审计 = 触发记录还原（G(r⊥) = 触发器快照），且 NSFL 不可逾越：
  NSFL-trigger(x) ⟹ Φ(x) = r⊥（熔断是映射行为，不是事后标注）。
- **策略**：把守卫写成定义域谓词，Φ 用 Lean 的 `PartialEquiv`/部分函数包；
  不可逾越性 = 守卫在 ⊗ 下保持（化合不剥离合规前置）。
- **风险点（原 P-3 张力）**：FUSED 的不可逆性与右逆存在性的张力——解法：
  右逆定义在 Im(Φ) 上，FUSED 态不在像集内（它是 r⊥ 类），不进入右逆定义域；
  该处理需作为设计决策写入证明文件的"模型假设"节。

### M-3 化合保持性（**承重命题**，★★，= P-7 降维的归纳步）
- **陈述**：若 Φ₁、Φ₂ 各有可计算反射广义逆 G₁、G₂，且 MOU 满足
  ε-可加（|m(Φ₁⊗Φ₂) − m(Φ₁) − m(Φ₂)| ≤ ε，ε 有累积上界 ε(n)），
  则 Φ₂∘Φ₁ 有可计算反射广义逆 G₁∘G₂；五可条件在 ⊗ 下逐项保持。
  > ⚠️ **精确化回填（2026-09-14，创始人裁定「要回填」）** —— 上式「取 `G₁∘G₂`」**系兼容条件成立时的版本**，非无条件简写。
  > 设 `f : D ⇀ R`、`g : R ⇀ S` 各存在像内还原的右逆 `gf`、`hg`，记复合 `Φ := g ∘ f`：
  > **① 兼容条件下（`gf ∘ hg` 版）**：若 `∀ s ∈ Im(Φ)： f (hg s) = some (hg s)`（即 `hg s` **落在 `f` 的像内**），则 `G := gf ∘ hg` 是 `Φ` 的右逆（像内还原）；
  > **② 一般情形（规范代表元版）**：不假设兼容条件，改取 `G_canon(s) :=` 任一使 `g (f x) = some s` 的 `x`（存在性由 `s ∈ Im(Φ)` 给出），则两条正则性公理成立；
  > **③ 另一层前置（不可与本条互替）**：`Im(f) ⊆ dom(g)`——属「类型匹配」，非本条内容。
  > **反例机制**：若 `hg s ∉ Im(f)`，则 `gf ∘ hg` **不是** `Φ` 的右逆。
  > 依据：`TDCA-TRACK-FORMAL-PROOF-001-M3-L3-PRECISION-001`（L3 口径精确化附注；原为**追加注**口径，本次**按创始人裁定回填入正文**）；形式化载体 = `TDCA/Compose.lean`（L3a 假设显式化 + L3b 规范代表元版）。
- **策略**：图追踪（diagram chase）：广义逆的两条公理逐分量验证；
  五可保持逐项验证（可观测=记录并集完备；可计量=ε 控制；可配置=配置权并置；
  可审计=G 复合；可熔断=守卫合取）。
- **关键引理**：ε-可加性的累积控制 ε(n) ≤ n·ε 或更好——这是 F2 的量化形态，
  证不出线性上界则主定理降级为 ε-形态（见 §四回退条件）。

### M-4 分形归纳主定理（= P-7 条件版，★★，条件于 ID-96）
- **陈述**：在 ID-96（场景分形假设）与 M-3 条件下，∀n，Φⁿ 存在可计算
  反射广义逆；且"五可 ∀n 成立 ⟺ 层内规模可持续"。
- **策略**：基例 M-0/M-2 + 归纳步 M-3 + 弱自相似极限（ID-96 的 F1 触发时
  主定理降级为带边界微扰项的形态）。
- **策略性说明**：此定理把原 P-7（百亿变量直接构造）降维为
  "单场景 × 保持性 × 归纳"，工程量从研究级降为工程级（条件估计见 P-7c 草案）。

### M-7 宪法一致性与定义域非空（= P-8 被统摄，★★）
- **陈述**：约束族 C₁₆ 可满足（∃ x, C₁₆(x)），故 dom(Φ) 非空；
  且 C₁₆ 在 ⊗ 下为内核约束（律一），场景注入不修改内核（律二）。
- **策略**：**见证构造**——TDCA 仓库自身即满足 C₁₆ 的模型（META-001
  自反化合的又一次运用：制度是自身的第一个模型）；
  内核性由律一/律二的静态检查（`stance_neutrality.py`，已 CI 化）提供工程证据。

### M-6 三锚不动点（= P-9，★★，外部依赖声明）
- **陈述**：结算/计量/确权映射 s、m、c 与 ⊗ 交换（锚保持性），
  即三锚空间是 ⊗ 的不动子空间。
- **策略**：接口不变量验证（每个锚的接入契约作为交换性条件逐一验证）；
  当前为 SIMULATED 接口，定理以 conditional 形态登记，真实态触发后升 Tier。

## 五、机器验证路径（Lean 4 + Go 双通道）

**里程碑 1（2-3 周）**：M-0/M-1/M-2 的 Lean 4 形式化——
类型骨架：`def Φ₀ : D → Option R`、`def Verify : R → Bool`、
`def G₀ : R → D`；定理：`theorem mp₁ : ∀ x, Verify (Φ₀ x) = true`、
`theorem mp₂ : ∀ r, Verify r = true → Φ₀ (G₀ r) = r`、
`theorem mp₃ : ∀ x, G₀ (Φ₀ x) = x`（像在 dom 上的截面性）。
（M-2 的两条正则性公理由 mp₂/mp₃ 合成。）

**里程碑 2（3-4 周）**：M-5 + M-7 形式化（部分函数包 + 见证构造）。

**里程碑 3（4-6 周）**：M-3 形式化（ε-可加作为显式假设引入，其验证为并行
实证任务）；完成则 M-4 为纯归纳（1 周内）。

**里程碑 4（外部触发）**：M-6 在真实锚接口落地后升 Tier。

**Go 通道**：NCA 哈希链与 NSFL 守卫的可执行断言（扩展 `VerifyAxiom6()`），
与 Lean 通道互相独立、互为冗余。
