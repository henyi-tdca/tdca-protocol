## 一、定位

本目录是 TDCA 形式化证明工程（Lean 4 + Mathlib）的源码与机验记录载体，覆盖：

- **抽象层**类型骨架与定理陈述（部分函数/重算比对模型）；
- **复合与保持性**（复合映射的定义域刻画、复合右逆、守卫保持）；
- **误差累积**（一致有界假设下的累积界）；
- **归纳步骨架**（层叠复合的右逆传递）；
- **场景形成机制的形式化子集**（可机验子集与业务层的两栏切分）。

**范围外（明示不做）**：本工程**不**声称任何制度层结论；不追求真逆（多对一映射的真逆不存在）；外部接口类命题不承诺时间表。

## 四、两栏切分（场景形成机制）

| 栏 | 内容 |
|---|---|
| **可机验（进证明器）** | 集合/定义层、值域与单调性、**见证方向**的涌现判据、合取导出、方向性判据 |
| **留业务 / 制度层（不进证明器）** | 阈值取值、意义锚定的本体论地位、效用来源语义、机制语义定性、**否定方向的不可判定性**、反馈系统的收敛性 —— ⛔ **不得以形式化名义使用** |

**⭐ 半判定性诚实边界**：该场景的候选集合**不可枚举/无界** ⟹ 「**不存在**候选」**不可有限步证否** → 本工程**只形式化「见证方向」**；相关充分性结论一律表述为「**（存在见证时）⟹ 结论**」，**引用时不得省略此限定**。
