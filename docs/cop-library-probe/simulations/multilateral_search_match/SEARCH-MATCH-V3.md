## 五 · 结论

- 引擎**不自带偏好**: 三套用户条件各自注入 ConstraintProfile, 推荐计划随之变化（稳健合规→Plan B 冗余, 快速上线→Plan A 最大V, 成本敏感→Plan C 最低成本）。
- 智能体**场景并行验证**: 每条件把用户敏感维度展开为验证场景, 用多进程并行跑 Plan A/B/C 存活矩阵, 交叉比对达标与加权得分。
- 偏好可完全自定义: `--profile-json` 让用户按自身条件自建约束档案, 引擎据此重排推荐, 不静默替用户决策。
