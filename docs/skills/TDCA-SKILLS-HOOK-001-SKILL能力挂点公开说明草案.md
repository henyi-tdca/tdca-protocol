## 一、能力挂点定位

「SKILL 能力挂点」= TDCA 官方智能体集群的**可调用能力卡点**——将官方智能体（矩阵 V2.2 在册）与专家 Skill 能力挂接的机制入口：

```
官方智能体（矩阵在册 26+） ──挂点──▶ 可调用 Skill 能力卡
                                      （注册/调用协议/NSFL 预检/MOU 锚定/NCA 记录）
```

## 二、Skill 制度定位（TDCA-SKILL-001 核心）

- **Skill 是中性技术对象，不是制度主体**——其制度价值仅在配置权调用过程中由协议赋予
- **三重中性**：技术中性（实现不预设制度立场）/ 场景中性（场景适配由调用配置权决定）/ 价值中性（价值判断由 NSFL 扫描与宪法审查注入）
- **创作者权利边界**：拥有 IP 效用（Tier 1），不拥有制度迭代权/配置权垄断权/负空间豁免权/税收规避权
- **被调用的知识才有价值**（ID77）——Skill 不调用 = 无价值；每次调用落 MOU 税收锚定 + NCA 嵌套认知资产记录

## 三、能力挂点组成

| 组件 | 说明 |
|---|---|
| 官方智能体 | 矩阵 V2.2 在册（官方子智能体索引，含类型/职能/调用关系） |
| Skill 能力卡 | 专家 Skill（官方/社区）；调用走配置权协议 + NSFL 预检 |
| cop-library | 515 COP 权威库（调用规格：¥0.01/次 + 15% 嵌套分润，开源方优先） |
| 机制规范 | TDCA-SKILL-001（定位/中性/边界）+ 官方智能体接入说明 |

## 四、调用纪律（对外承诺）

- 每次 Skill 调用过 NSFL 负空间预检（fail-closed）+ MOU 锚定 + NCA 存证
- Skill 挂点只赋能不改码（外部智能体只读接入）
- 15% 嵌套分润模拟态记账（ID92）

## 五、门户卡口径

「SKILL 能力挂点」= TDCA 官方智能体 × 专家 Skill 的能力挂接机制：SKILL-001 中性定位 + 官方智能体矩阵 + cop-library（515 COP）——被调用的知识才是有价值的知识（ID77）。
