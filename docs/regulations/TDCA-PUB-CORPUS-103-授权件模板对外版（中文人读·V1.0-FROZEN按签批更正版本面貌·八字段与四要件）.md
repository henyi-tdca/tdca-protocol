# TDCA-TEMPLATE-AUTH-001 · 授权件模板（中文人读版）

版本：V1.0-FROZEN ｜ 生效日期：2026-10-03

---

## 一、性质与适用范围

本模板规定**授权件**的固定格式与必备要件，供授权方与被授权方填写、签署与核对。

- **授权件**是"谁授的、授给谁、授什么、授到什么时候"的书面凭证；
- 无论资产归属**自有或他有**，进行配置类使用**均须持有有效授权件**；
- 特别条款与自定义条款以智能合约约定，主体字段不得自定义。

## 二、固定格式（八字段）

| 序号 | 字段 | 必填 | 填法与边界 |
|---|---|---|---|
| F1 | 提交主体 | 必填 | 权属方或经其授权的提交方；须为法律主体；智能体不代填 |
| F2 | 被授权方 | 必填 | 受权主体；多层转授逐层单列 |
| F3 | 场景 | 必填 | 归属场景明列；未列明场景不在授权范围 |
| F4 | 权限范围 | 必填 | 可调用或可配置的范围与动作类型；不得含负空间动作 |
| F5 | 期限 | 必填 | 起止时点；不设期限须显式写明，不得留空 |
| F6 | 层级 | 转授时必填 | 本件所处授权层级；层数上限依在册制度与合同 |
| F7 | 分成 | 必填 | 对价与分成安排；具体比例依在册制度与合同 |
| F8 | 撤销条件 | 必填 | 撤销之触发与生效方式；撤销须本人签署 |

## 三、四要件（缺一不成立）

| 序号 | 要件 | 对应栏位 | 判定 |
|---|---|---|---|
| R1 | 场景约束 | F3 场景 | 必带场景 |
| R2 | 五阶资产形态 | 附件栏「五阶清单」 | 须列明覆盖之阶；未列明之阶不得据本件主张 |
| R3 | 全构成已授权 | 声明栏「全构成声明」 | 须声明无未披露保留；有保留须显式列明（有保留即未达全构成） |
| R4 | 法律主体签名 | 签署栏 | 本人签署（电子签名或授权码）；智能体不代签、不代持、不代填 |

补充两条：

- 缺一即**授权不成立**（无件不得配置、无授权不得调用）；
- 撤销亦须**本人签署**。

## 四、模板正文（填空式）

```
【授权件】TDCA-AUTH-<编号> ｜ 版本 <V> ｜ 数据性质 <REAL|SIMULATED>

一、提交主体（F1）：<法律主体名称／身份标识>
二、被授权方（F2）：<受权主体>                    ※ 多层转授逐层单列
三、场景（F3）    ：<归属场景>                    ※ 未列明场景不在授权范围
四、权限范围（F4）：<可调用／可配置之范围与动作类型>
五、期限（F5）    ：<起始> ~ <终止>                ※ 不设期限须显式写明
六、层级（F6）    ：第 <n> 层
七、分成（F7）    ：<对价与分成安排>
八、撤销条件（F8）：<触发与生效方式>              ※ 撤销须本人签署

【四要件声明】
  R1 场景约束       ：同上 F3
  R2 五阶资产形态   ：<覆盖之阶，逐项列明>
  R3 全构成已授权   ：已声明全构成 ／ 有保留（保留项逐条列明）
  R4 法律主体签名   ：<本人签署，电子签名或授权码>

【特别条款／自定义条款】以智能合约约定
【引用与存证】每次引用与签署动作留痕（主体、时间、要件版本、动作类型）
【公开面映射】登记后按四项字段公示：权属信息／授权信息／授权状态／获取方式
              （获取方式不等于已获授权）
```

## 五、两式

| 式 | 用法 | 边界 |
|---|---|---|
| 规范式 | 直接采用第四节填空体例 | 八字段不得增删，不得改字段语义 |
| 自定义式 | 就特别条款另拟（如阶梯分成、条件性撤销） | 仍须含八字段与四要件；特别条款以智能合约约定 |

## 六、与准入、变更、转授、例外之衔接

1. **准入**：配置类调用须持有效授权件；授权件失效（撤销或要件缺损）即拒绝。
2. **变更**：预收权、实时授权、追加授权、许可变更、多层级授权，每次操作均须落件（变更即新版本）。
3. **状态**：授权状态随操作同步（待生效／有效／已变更／已撤销／已到期）。
4. **多层转授**：每层皆须件、皆须签；任一环失效，其下游全部失效。
5. **例外**：沙盒内与演练免件；出盒必须取得授权，无授权不得出盒。

## 七、公示字段

登记后对外可查四项：**权属信息**、**授权信息**、**授权状态**、**获取方式**。

其中「获取方式」表示取得授权的途径，**不等于已获授权**。

## 八、填写留白

以下数值**不预设**，由授权双方依在册制度与合同填写：分成比例与对价形式、期限默认值、层级上限、授权码有效期（一次性或可复用）。

## 九、边界

本模板只规定格式与要件，不构成法律意见；具体授权条款以双方正式授权件与合同为准。授权件的签署须由法律主体本人作出，智能体不得代签。
