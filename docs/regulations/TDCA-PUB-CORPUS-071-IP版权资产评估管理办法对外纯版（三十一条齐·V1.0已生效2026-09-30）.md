# IP 版权资产评估管理办法

**版本** V1.0（已生效，2026-09-30） ｜ **修订** 由草案转正式版；条文未改

---

## 第一章总则

**第一条（目的）** 为规范生态内 IP 版权资产的评估活动，使之**可观测、可计量、可审计、可归因**，并使评估结果能与**入表与确权**衔接，制定本办法。

**第二条（适用范围）** 适用于生态内对 IP 版权资产的**效用价值评估**及其**入表与确权的衔接**活动。所评资产类别涵盖版权的内容资产，以及数据资产、商标资产、专利资产的相应权利；**具体范围依评估目的确定**。

**第三条（与既有制度之关系）** 本办法为管理办法类，依人机双版本原则同批产出中文人读版、英文人读版与机读版；**人读版为语义权威**，机读版不得反向改语义。制定照制度转正程序，验证与出盒照三空间循环机制，达标判据为**通过制度规范审查即达标**（程序性达标，非自评、非数值门槛）。

**第四条（基本原则）**
1. **合规前置**：先合规、后效用，不可倒置；
2. **最小配置单元是场景**：场景内部要素不直接参与配置（不越级）——**无"全能方"**；
3. **协作 ＝ 编排的叠加／嵌套（化合，有保持条件）＋ 正和满意解 ＋ 存证**；未达成者为"**未成立之协作**"，属**合法终态**；
4. **满意解不等于最优解**；**人类保有最终决策权**。

**第五条（语言与版本）** 中英文版本**逐条对应**（禁漂移），术语照在册术语表；版本号与哈希可溯源。

## 第二章术语与定义

**第六条（术语引在册）** 本办法所引术语照在册定义，**不新造**：沙普利值分配、正和效用、最终受益人、场景等。

**第七条（本办法特用术语的操作定义）** 照术语三要素格式（**是什么／不是什么／边界条件**）立定义：
1. **IP 版权资产**——是什么：以**内容**为标的、**可显式标注唯一性**，并具**可授权、可复用、可二次开发利用**特质的资产；涵盖依各自法域归口的数据资产、商标资产、专利资产；
2. **效用价值**——是什么：**场景约束下、有效时间内**的效用价值；不是什么：不是静态数值，不是主观估值；边界条件：**无场景时效维度者不成立**；
3. **可观测下限**——是什么：**销项之和 ＋ 进项之和**（**地板值**）；不是什么：**不是天花板，不是效用最大值**；边界条件：照在册可观测性口径。

## 第三章评估对象与范围

**第八条（范围依据）** 评估范围**与评估目的相关**，**由评估目的确定**（不设固定列举清单）；提起与受理均须**载明评估目的**。

**第九条（排除项 · 负空间）** 落入**法律负空间**（绝对禁止领域）的标的**不得入评**；评估活动本身须**先过负空间前置检查**，不通过即不得进入沙盒验证区。

*这一条防的是：先评了再问"这东西能不能碰"。*

## 第四章评估方法

**第十条（可观测下限法）** 效用价值的量化取**可观测下限**：**销项之和 ＋ 进项之和**（地板值口径）。

**第十一条（五阶分层分列）** 五阶效用**分层分列**，**不得合并为单一"产出率"**——五阶是**协同拟合**，不是加总。

**第十二条（税与税收口径 · 两税分列）**
1. **印花税**：纳税主体为配置调用的**合同当事人**；税源为**场景调用配置**；计税基为调用配置额乘**在册给定比率**；计入税收总和；
2. **增值税**：纳税主体为**交付方**；税源为**业务交易**（正空间）；计税基为交易额乘**法定税率**；计入税收总和，并计入企业税收贡献；
3. **纪律（硬）**：两者**主体不同、税源不同、发生环节不同**——**不得合并计税、不得互相替代**；若两税基不相等，**须分别取数**；
4. **税收总和须含两类税**；仅计其一则**量级失真**；
5. 税源归属照既定核定：印花税源于场景调用配置，增值税源于业务交易（正空间）。

注：具体比率与税率以在册给定值与现行税法为准，随税法变动而更新。

**第十三条（出盒门槛）** 出盒的**唯一门槛**是**财政自给**（取值照在册经济口径）；正和指数、沙普利值、税收总和在本设定下**恒成立**，**非独立门槛**。

**第十四条（方法纪律 · 硬）**
1. **只给可观测下限，不给主观估值**；
2. **禁止以效用最大化替代制度约束**；
3. 资产价值照五元组（效用、规模、财务、合规、风险）计算，**风险为负即一票否决**；
4. 三分段评估**本版未实现**（后续补）；
5. 增值税进项抵扣**本版未含**（后续补）。

*这一整节防的是：把"估出来一个数"当成本事——评估只给地板，不给想象。*

## 第五章评估程序

**第十五条（发起）** **发起主体不作规定**（任何主体皆可发起）；评估方可**要求所有权人按规范提交评估材料**，材料清单照在册登记模板八部分（委托方类型、评估目的、评估基准日、风险等级、权属证明等）。

**第十六条（评估 · 协作）** 评估由**智能体协作**完成（配置权调用照在册机制）；全过程照观测六项留痕：**投标、组队决策、配置调用、制度遵守、时限与成败、归因**，并**覆盖协作调用链**。

**第十七条（核证）** 评估结果须经**独立核证**：**门侧与书写侧不得同人**。

**第十八条（时限与成败）** 时限原则上**一天内**；**方数不预设**；**不预设一定成功**——未达成满意解为**合法终态**。

**第十九条（周期与触发 · 实时 · 动态 · 不预测）** 评估**只有场景约束下、有效时间内的效用评估**，是**动态效用函数的刻画**（非静态数值评估）；**可实时出报告**；**不预测**（不设预测窗口、不作趋势外推）。

**第二十条（过程为观测重心）** 观测重心是**过程**（协作 → 配置调用 → 达成满意解）；三层须分清：**办法是解，过程是观测量，审查通过是出盒条件**。

## 第六章入表与确权

**第二十一条（会计口径对接）** 入表口径照在册效用价值评估系统的入表服务（对接会计口径与版权链上链）。

**第二十二条（确权锚）** 版权链确权为**三锚之一**；当前为**模拟态**——本办法相关条款**以模拟态表述为准**，真实态触发后**另行修订**。

## 第七章纪律与禁止

**第二十三条（禁止事项）** 禁止：① 出具**主观估值**；② **以效用最大化替代制度约束**；③ **未留痕**的评估；④ **越出配置权边界而不熔断**；⑤ 将两类税费**合并计税或互相替代**；⑥ **对评估方法与计算算法提出争议**。

**第二十四条（违规处置）** 照三空间四路处置：**实时熔断** → **回退沙盒** → **轻微限期重整重返** ／ **中度深度整改需裁决** ／ **严重永久休眠**；并生成**熔断存证**。

## 第八章争议与处置

**第二十五条（争议路径）** 评估争议**仅限"数据采集保真"**（数据来源、采集过程与留痕的保真性）；**评估方法与计算算法不接受争议**——属既定事项，**不因争议而变更**；涉及**制度语义**的争议照在册制度裁决机制分别处理。

**第二十六条（审计与归因）** 一切评估与处置须落**全链存证**，**覆盖协作调用链**，以保证事后**可追溯、可归因**。

**第二十七条（审计独立性局限 · 如实）** **复核独立性存在制度性局限**——此处**如实标注**，**不宣称完全独立**。

*这一条防的是：把"我们审过了"讲成"我们绝对独立"。*

## 第九章附则

**第二十八条（已定项）** 原七项未定项**全部已定**：操作定义（三要素格式，涵盖数据／商标／专利三类）／评估范围（随目的确定，不设固定清单）／发起主体与材料（主体不设限，可要求按规范提交）／周期与触发（场景约束、有效时间、动态、实时、不预测）／争议裁决（仅限数据采集保真）／生效与修订程序（照制度管理规范）／过渡衔接（照既有制度）。

**第二十九条（双版本与生效）** 本办法**同批**产出**中文人读、英文人读、机读**三版，**版本号与哈希一致、可溯源**；生效与修订照制度治理规范，**走完程序即生效**，不另设专门门槛。首版自 **2026-09-30** 起生效，版本 `V1.0`。

**第三十条（过渡衔接）** 过渡事项照既有制度的规定办理。

**第三十一条（对外口径）** 制度韧性实证**暂不对外**。本办法的公开发布照在册分工由执行侧按规定流程办理——起草方**不代推送、不代合并**。
