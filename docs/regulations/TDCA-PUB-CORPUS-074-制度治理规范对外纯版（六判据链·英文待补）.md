# 制度治理规范

**版本** V1.0（中文对外版，2026-10-18） ｜ **英文对外版** 待补（见文末说明）

---

## 一句话

一件事要成为制度，须依次过**六道判据**：**是不是**制度性文件 → **要不要**人机双版本 → **够不够格**当正式制度 → **该不该立**（先审必要性、再验四性）→ **划不划得来**（全生态经济性）→ **钱从哪来**（收入口径）。

*这一节防的是：凭一句话就立规矩，或凭一句话就废规矩。*

---

## 判据一 · 是不是制度性文件

**属制度性体裁的九类**：原则 ／章程 ／规则 ／规范 ／条例 ／纪律 ／标准 ／定式 ／合约（并含宪法 ／准则 ／红线 ／铁律 ／禁令 ／制度）。

**另五类亦属制度性文件**：手册 ／指引 ／指南 ／细则 ／流程——但**版本要求单由判据二决定**。

**且**须对执行事务有**硬约束**（手册、指引、指南除外，它们"给人看"）。

**不属制度性的**：评估 ／审查 ／记录 ／清单 ／提案 ／决议 ／裁决 ／裁定——或无硬约束，或系一次性动作。

## 判据二 · 须不须双版本

| 体裁 | 版本要求 |
|---|---|
| 手册 ／指引 ／指南（给人看） | **仅人读版** |
| 细则 ／流程件（涉事务执行） | **人读版 ＋ 机读版（同批）** |
| **对外发布件** | **三件套**：中文人读 ＋ 英文人读 ＋ 机读 |
| 补版本前 | **再审一遍**，三出口：须补 ／审后免补 ／改判 |

**语义权威**：**人读版为权威**，机读版**不得反向改语义**。

*这一节防的是：两版各说一套，谁都能引对自己有利的那一版。*

## 判据三 · 够不够格当正式制度

**四阶阶梯**：**草案 → 提案 → 条例（正式制度）→ 作废／被取代**。

**未成条例者只能算草案或提案**，不得转作正式制度文献。

**转正四步（缺一不成）**：
| 步 | 名称 | 要求 | 证据 |
|---|---|---|---|
| ① | **过智库** | 由智库研究起草（问题定性／方案／负空间／替代方案） | 起草件 |
| ② | **过研发治理包** | 挂治理包各闸（试验闸／灰度闸等逐条对齐） | 挂门记录 ＋ 闸门结论 |
| ③ | **形式化证明或可机验断言**（二者其一即可） | 证明件，或"断言 ＋ 机验命令 ＋ 预期结果" | 证明件／机验器／断言清单 |
| ④ | **沙盒验证** | 提交沙盒验证，通过后出条例 | 沙盒验证记录 |

**失败规则**：四步缺任一、或证据不可核，**只能称草案／提案**，**不得称正式制度**。

## 判据四 · 沙盒验证两段

**先审必要性**：要解决什么 ／现在办还是缓办 ／属填补空白还是打补丁还是修订还是增订 ／**必要与否由实际问题裁决**——现有制度**盖不住则必要**，**盖得住则不立**。

**再验四性**：**可靠性**（机制靠得住）／**可行性**（落得下去、可执行）／**经济性**（见判据五）／**冲突与效力适用约束**（与既有制度是否冲突；**效力按场景层级适用**）。

*这一节防的是：为了"有个制度"而立制度。*

## 判据五 · 经济性（全生态口径）

| 项 | 口径 |
|---|---|
| **边界** | **全生态**——不缩到单层、单场景族算账 |
| **成本** | 算力支出 |
| **收益** | 制度效力产生的**资产性收入** |
| **硬线** | **执行成本不得大于解决问题的成本** |
| **局部与全局** | **局部亏、全局赚，仍算经济** |
| **时间** | **不设时间窗**（看既有运行能否持续） |
| **有效解决** | 覆盖失效范围后，**制度性收入恢复或增加** |

## 判据六 · 制度性收入口径

**协议层免费 ＋ 资产配置收费**。收入来源为**配置权调用与调度的计量**（资产专用税／配置权调度税）。**不向协议层本身收费**，**不另立新费目**。
