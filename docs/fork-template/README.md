# TDCA 主动 Fork 模板（借船出海）

> 对热门开源项目**主动 Fork + 协议挂载**的标准件——**不改上游任何源码，仅追加协议层文件**。
> 完整模板（README 附加声明逐字稿 + TDCA-Agreement.yaml + 分润话术）：[TDCA-FORK-TEMPLATE-001.md](TDCA-FORK-TEMPLATE-001.md)

## Fork 前三查（纪律）

| # | 检查 | 说明 |
|---|---|---|
| 1 | **许可校验** | 上游 LICENSE 为宽松许可（MIT / Apache / BSD）——GPL 传染性不做 |
| 2 | **活跃确认** | 近 30 天有提交（非死仓） |
| 3 | **去重** | 同仓库 7 天内不重复 Fork 建议（台账负责） |

## 三条红线（不可绕过）

1. **不改上游源码**——Fork 副本只追加协议层文件（README 声明 / TDCA-Agreement.yaml / tdca-mcp-bridge 挂载配置），上游文件零改动
2. **许可校验先行**——保留上游版权与许可声明，TDCA 协议层独立 Apache-2.0，不覆盖上游
3. **正和感话术 + 模拟态分润**——分润一律模拟态口径（NCA 确权 + ERI 权重记账，真实结算接口开通前无真实现金流）；禁止「真实打款」类承诺

## 边界澄清

- 上游项目条款始终优先；15% 版税基准不覆盖任何项目的许可
- 上游可选择用或不用本协议层——配置权归上游（只赋能不改码）
- 上游许可变更 → 停止并撤销

## 关联

- 执行器：`ecoscan/` 的 AutoForker（五门判定 + 材料生成 + NCA 台账，半自动——创始人确认后才执行 Fork）
- 制度依据：TDCA-OPEN-COLLAB-001（挂载/分润）｜ BIDIR-001（只赋能不改码）｜ AUDIT-001（许可校验）
