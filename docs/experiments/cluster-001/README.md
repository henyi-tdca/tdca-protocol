# Cluster-Orchestration Experiment 001（集群编排试验 001）

本目录为一项**实验性**编排试验：用同一任务比较**三组**（A 制度对照／B 四角色走查／C 一致性），
判据（J-1~J-4）**先写死**，产物一律标 **SIMULATED**，**不主张**任何真实世界效果，**不得**据以主张制度有效。
复跑请从 `repro.zh.md`（或 `repro.en.md`）开始；方法见 `plan.*.md`，任务与回报格式见 `taskbook.*.md`。

术语：**组（arm）** ＝ A／B／C；**编排（orchestration）** ＝ A 组内所跑的四种做法。

## English

This directory hosts an **experimental** orchestration experiment: one task compared across
**three arms** — A (institutional contrast), B (four-role walkthrough), C (consistency).
Criteria J-1…J-4 are **fixed in advance**; every artifact must be labelled **SIMULATED**. This
experiment claims **no** real-world effect and **must not** be cited as evidence that any
institution is effective. Start with `repro.zh.md` (or `repro.en.md`); the method is in
`plan.*.md`; the task and reporting format are in `taskbook.*.md`.

Terminology: **arm/group** = A / B / C; **orchestration** = the four variants run inside arm A.
