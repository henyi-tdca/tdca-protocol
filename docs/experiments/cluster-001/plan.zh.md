# TDCA 集群编排试验 · 方案（实验性）

> 性质：**实验性方法说明**。本试验**不主张**任何真实世界效果，**不得据以主张制度有效**。
> 一切产物一律标注 **SIMULATED**（模拟态）。

## 一、目的
在「广度」方向取得**可判读的行为层证据**：① 走查加厚；② 制度增量之仿真对照；③ 必要时一致性旁证。

## 二、分组与口径（严格分口径）
- **A 组（制度对照）**：同一任务，四种编排各跑 **3 轮**——① 裸跑；② ＋存证；③ ＋归因；④ ＋熔断校验。
  ⚠️ 独立成组；与其他实验的对照表**不得共用、不得混称**。
- **B 组（四角色走查）**：调研／批判／裁决／记录四角色分离。⚠️ **批判与裁决不得同一上下文**；产物表格化，发现项须可溯源。
- **C 组（一致性）**：同题起 **3 个互不知情**的子代理；⚠️ 同题同口径，分工互不可见。

## 三、判据（先写死）
| 判据 | 定义 | 判定线 |
|---|---|---|
| J-1 产出完整性 | 每轮实际产物件数 ÷ 要求件数 | ＝1.0 |
| J-2 冲突检出率 | 检出行数 ÷ 注入项数（检出＝逐位对账命中；须注明注入项数来源） | ≥0.9 |
| J-3 返工轮次 | 同一产物因**自身缺陷**回退重做次数（外部输入变更不计） | ≤1 |
| J-4 一致性吻合度（仅 C 组） | 一致点数 ÷ 总点数（分歧点逐项列明） | ≥0.8 |

## 四、口径铁律
一切数字**不得**写成「制度有效」；允许之表述**仅**：「给定该编排下之差异」。不主张真实世界效果／制度生效／归因于任何组织。

## 五、落盘与记账
中间产物**全落盘**（含失败轮、空轮、中止轮；只留成功轮视为凑数）；一律标 **SIMULATED**；每轮记**可复核窗口**（起止时刻，含 UTC 双记）；token 台账可报，**货币成本**由发起方按自有口径回填。

## 六、停手条件
S-1 以「中转」冒充一层产物 ⟹ 停并报；S-2 需改既有件或契约语义 ⟹ 停并报；S-3 需联网／推送／对外 ⟹ 停（全程本地）；
S-4 发现凭据字面 ⟹ 停并只报位置与类型；S-5 成本或数值不可得 ⟹ 如实报不可得、**不得估填**；S-6 与基线不符或降维取舍 ⟹ 报回不结案。
