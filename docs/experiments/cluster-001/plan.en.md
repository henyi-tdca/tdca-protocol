# TDCA Cluster-Orchestration Experiment — Plan (Experimental)

> Nature: an **experimental method note**. This experiment claims **no** real-world effect and
> **must not be cited as evidence that any institution is effective**. All artifacts must be
> labelled **SIMULATED**.

## 1. Purpose
Obtain **readable behavioural evidence** along the "breadth" axis: (a) thicker walkthroughs;
(b) simulated contrast of institutional increments; (c) consistency corroboration when needed.

## 2. Groups (strictly separate)
- **Group A (institutional contrast)**: one task, four orchestrations × **3 rounds** each —
  ① bare; ② +attestation; ③ +attribution; ④ +circuit-breaker check.
  Comparisons must **not** be shared with, or conflated with, other experiments.
- **Group B (four-role walkthrough)**: research / critique / adjudication / recording, kept separate.
  **Critique and adjudication must not share one context**; outputs tabulated, findings traceable.
- **Group C (consistency)**: **3 mutually unaware** sub-agents on the same task; same prompt,
  same rubric; roles invisible to each other.

## 3. Criteria (fixed in advance)
| Criterion | Definition | Threshold |
|---|---|---|
| J-1 completeness | artifacts produced ÷ required per round | = 1.0 |
| J-2 conflict detection | detected lines ÷ injected items (detection = exact per-digit match; state the source of the denominator) | ≥ 0.9 |
| J-3 rework rounds | rounds redone due to **own** defects (external input changes excluded) | ≤ 1 |
| J-4 consistency (Group C only) | agreeing points ÷ total points (list disagreements) | ≥ 0.8 |

## 4. Non-negotiable wording
No number may be described as "the institution is effective"; the only permitted phrasing is
"the difference observed under the given orchestration".

## 5. Artifacts & accounting
All intermediate artifacts retained (including failed, empty and aborted rounds); everything
labelled SIMULATED; each round records a **reproducible window** (start/end, local **and** UTC);
token accounting may be reported; monetary cost is filled in by the initiator.

## 6. Stop conditions
S-1 fabricating a layer via shims ⟹ stop and report; S-2 altering existing artifacts or contract
semantics ⟹ stop and report; S-3 any need for network / push / external exposure ⟹ stop;
S-4 credential literals found ⟹ stop, report location and type only; S-5 cost or values
unavailable ⟹ report as unavailable, **never estimate**; S-6 mismatch with the stated baseline or
any scope reduction ⟹ escalate, do not close.
