# TDCA 集群编排试验 · 任务书

> 面向任何具备**本地多会话／多角色编排**条件的一方，**可自行复跑**（见配套《复跑说明》）。
> 实验性。**不得据以主张制度有效**；产物一律标 **SIMULATED**。

## 一、参数
组别 **A＋B＋C 三组全跑**；轮次／规模 **A 组 3 轮**（四种编排各 3 轮）／**B 组 1 轮**／**C 组 3 个子代理**；
判定线 **J-1＝1.0；J-2≥0.9；J-3≤1；J-4≥0.8**。不达标即**如实报不达标**，不得改口径、不得估填。

## 二、交付（4 项）
1. 逐组逐轮**原始产物清单**（件数、路径、SIMULATED 标注）；
2. **J-1~J-4 逐项数值**＋口径注明（分子分母分别写明）；
3. **可复核窗口**（起止时刻，含 UTC 双记）＋ token 台账（货币成本留空，由发起方回填）；
4. 声明：未对外、未推送、未改件、**未以中转冒充一层**、**未凑数**、**未估填**。

## 三、纪律
中间产物全落盘；数字**不得**写成「制度有效」，允许表述仅「给定该编排下之差异」；停手条件见方案 §六，遇之即停并如实报。
