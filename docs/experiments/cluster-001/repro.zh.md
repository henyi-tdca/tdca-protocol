# TDCA 集群编排试验 · 复跑说明

> 目的：让任何一方**独立复跑**并得到同类可判读结果。⚠️ 结果**不得**据以主张制度有效。

## 一、环境
**全程本地**、无需联网；记录编排工具与版本、操作系统、时区。**组内角色上下文隔离**是关键前提。

## 二、准备
① 选定一个**固定任务**（A／B／C 同题同口径）；② 准备**注入项**并**固定其数量与来源**（J-2 分母，须注明依据）；③ 拟定每轮**要求产物件数**（J-1 分母）。

## 三、步骤
- A：同一任务，四种编排各 3 轮——裸跑／＋存证（每轮附可核对存证）／＋归因（标注冲突归属）／＋熔断校验（越界触发中止并记录）。
- B：一次四角色分离走查，**批判与裁决不同上下文**，产物表格化、发现项可溯源。
- C：同题起 3 个互不知情子代理，汇总一致点与分歧点。

## 四、记录与计算
每轮记起止时刻（本地＋UTC 双记）；J-1~J-4 **分子分母分别写明**；保留中间产物（含失败轮）；一切标 **SIMULATED**。

＋ 产物清单（路径）＋ 声明 4 项。

## 六、可复现性
含随机源者**记录种子**，同输入应同输出；失败／中止轮**保留并如实标注**。

## 七、免责
实验性方法；**不得**据以主张制度有效，亦不得据以主张任何真实世界效果。
