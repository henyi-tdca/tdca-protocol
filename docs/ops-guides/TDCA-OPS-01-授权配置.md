## 一、这一步在做什么

把「谁可以用、用到什么程度、在什么条件下用」说清楚，并留下**一份能被人核对的凭证**。
授权 不得是一句「你可以用」；它要能回答四件事：**谁授的、授给谁、授什么、授到什么时候**。（依流程环节流程环节卡 §一）

⚠️ **硬口径（照录）**：**授权须由法律主体本人作出**（本人签署或本人电子签名／授权码）；不得**智能体不得代签**。

---

## 二、开始前要备齐什么（依流程环节流程环节卡 §二）

| 项 | 要求 |
|---|---|
| 授权对象 | 被授权一方之**主体名称**（不得用昵称或账号名代替） |
| 授权标的 | 配置权 ／ 内容 ／ 工具 ／ 数据 —— **逐项列**（不得写「相关资产」一类笼统话） |
| 授权范围 | 场景、期限、次数或用量、地域 —— **逐项写**（不得写「等」） |
| 授权条件 | 前置条件与限制（可否再授权、可否商用、须否标注来源） |
| 授权件 | 按固定格式填写（八字段：授权方／被授权方／标的／范围／期限／条件／签署／凭据号） |
| 凭证 | 签署件或授权码（**码值只由本人持有，不得不入公开件**） |

---

## 三、按序怎么做

| 步 | 动作 | 依据 |
|---|---|---|
| `1` | 打开并确认站内对应的功能入口 | 依本族编写规格 |
| `2` | 写明**被授权方主体名称**（核过名称，不得用昵称／账号名） | 流程环节卡 §二 |
| `3` | 逐项列出**授权标的**（配置权／内容／工具／数据） | 流程环节卡 §二 |
| `4` | 逐项写出**授权范围**（场景、期限、次数或用量、地域） | 流程环节卡 §二 |
| `5` | 写出**授权条件与限制**（可否再授权、可否商用、须否标注来源） | 流程环节卡 §二 |
| `6` | 由**授权方本人**签署，或由本人出**授权码**（不得智能体代签） | 流程环节卡 §一 硬口径 |
| `7` | 按**八字段固定格式**填写授权件，逐格填满 | 流程环节卡 §二／§四 |
| `8` | 将授权件交被授权方留存，双方各能**核出**「授了什么、到什么时候」 | 流程环节卡 §四 |
| `9` | 写明**撤回路径**（谁提、怎么提、撤回后已发生的使用如何处理） | 流程环节卡 §四 |

时间口径（依流程环节流程环节卡 §三）：范围清楚、条件现成 ⟹ **当日可出**；需多层级或多主体逐层签 ⟹ **按各方签署节奏**（⚠️ **待运维核定**）；超时未有件 ⟹ 不得**不视为已授权** —— **未出件即不得开始使用**。

---

## 四、做完自检（依流程环节流程环节卡 §四 · 照录四条）

1. **四要件齐**：授权方、被授权方、标的与范围、期限与条件 —— 缺一不成立；
2. **八字段满**：授权件按固定格式填写，**无空格**；
3. **可核对**：任一方拿授权件能核出「授了什么、到什么时候」；
4. **可撤回**：撤回路径写明。

---

## 五、走不通怎么办（依流程环节流程环节卡 §五 · 七类照录）

| # | 现象 | 什么意思 | 怎么办 |
|---|---|---|---|
| `1` | 只有口头「你可以用」 | 无凭证 | 不得不用；补出授权件后再使用 |
| `2` | 授权件字段缺项 | 不可核对 | 补填；补不齐的按「未成立」处理 |
| `3` | 范围写「等」或「相关」 | 边界不清 | 逐项重写；不确定的不写进去 |
| `4` | 期限不写 | 永久？还是无限期？ | 必须写明起止或「至撤回为止」 |
| `5` | 由智能体代为签署 | 越权 | 不得不成立；退回由本人签署 |
| `6` | 授权码被公开或转发 | 凭据外泄 | 立即换码并留痕；不得不沿用旧码 |
| `7` | 撤回后仍在被使用 | 越界使用 | 书面告知停止；继续使用走争议入口 |

---

## 六、多久、同步还是异步、超时怎么办（照流程环节卡 §六 三句固定话）

1. **通常多久**：范围清楚当日可出；多层级签署按各方节奏（**待运维核定**）；
2. **同步还是异步**：异步，以**授权件（含凭据号）**为准；
3. **超时怎么办**：未出件即视为未授权，不得不得先使用后补件。
