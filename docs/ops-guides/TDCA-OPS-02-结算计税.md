## 一、这一步在做什么

把这一趟**该收该付算清**，按适用税法与在册制度**计税**，并留下**能被人复算的凭据**。
结算解决「**多少**」；计税解决「其中哪一部分依法要缴、缴给谁、按什么凭据缴」。（依流程环节流程环节卡 §一）

⚠️ **硬口径（照录）**：**计税依据须可回溯**（计量记录 ＋ 合同 ＋ 适用税法），不得不许「按经验估一个数」。

---

## 二、开始前要备齐什么（依流程环节流程环节卡 §二）

| 项 | 要求 |
|---|---|
| 计量记录 | 用了多少、做了什么（次数／用量／成果／配置权使用），**可核** |
| 结算单 | 应收应付、计算过程、双方确认 |
| 计税依据 | 交易性质、金额、适用税目与**依据条文位置** |
| 凭据 | 支付凭据、票据或等效凭证（**编号与金额须与结算单一致**） |
| 争议材料 | 对数字有异议时的**同一套材料**（供双方复算） |

## 三、按序怎么做

| 步 | 动作 | 依据 |
|---|---|---|
| `1` | 打开并确认站内对应的功能入口 | 依本族编写规格 |
| `2` | 先把**计量记录**取齐（次数／用量／成果／配置权使用，逐项可核） | 流程环节卡 §二 |
| `3` | 按计量与合同条款**算应收应付**，计算过程写在同一张结算单上 | 流程环节卡 §二／§四 |
| `4` | 标出**交易性质与金额**，对照适用税目，写明**依据条文位置** | 流程环节卡 §二／§一 硬口径 |
| `5` | 双方**确认结算单**（有异议先复算，见第 `8` 步） | 流程环节卡 §四 |
| `6` | 依结算单出**凭据**，核对凭据编号与金额 与结算单一致 | 流程环节卡 §二／§五 第 `5` 类 |
| `7` | 把**挂账、未结、待定项**逐条列明（不得留暗项） | 流程环节卡 §四 |
| `8` | 有异议 ⟹ 出**同一套材料**供双方复算；仍不一致 ⟹ 走争议入口（对应第 `17` 环节） | 流程环节卡 §五 第 `4` 类 |

时间口径（依流程环节流程环节卡 §三）：计量齐、无异议 ⟹ **按合同结算周期**；需对账或跨主体核数 ⟹ **按对账节奏**（⚠️ **待运维核定**）；逾期未结 ⟹ 不得**不视为放弃** —— **书面催告并留痕**。

---

## 四、做完自检（依流程环节流程环节卡 §四 · 照录四条）

1. **数字可追**：每个金额都能追到计量记录与合同条款；
2. **税目清楚**：缴什么、为什么缴、依据在哪，写得出来；
3. **凭据齐全**：结算单与支付凭据**一一对应**；
4. **无暗项**：挂账、未结、待定项**逐条列明**。

---

## 五、走不通怎么办（依流程环节流程环节卡 §五 · 七类照录）

| # | 现象 | 什么意思 | 怎么办 |
|---|---|---|---|
| `1` | 没有计量就结算 | 无依据 | 补计量；补不了的按合同约定方式处理 |
| `2` | 先付款后对账 | 顺序倒置 | 不得不从；先对账再结算 |
| `3` | 税目说不清 | 合规风险 | 按适用税法与在册制度核定；不清楚的书面请示 |
| `4` | 两方金额对不上 | 争议 | 出同一套材料供双方复算；仍不一致走争议入口 |
| `5` | 凭据与结算单金额不符 | 账实不符 | 以凭据为准更正结算单，并留更正痕迹 |
| `6` | 一方要求「先开票后核实」 | 风险 | 不得不从；按核实后开具 |
| `7` | 挂账长期不清 | 账不明 | 列挂账清单定期清；超期须书面说明 |

---

## 六、多久、同步还是异步、超时怎么办（依流程环节流程环节卡 §六 三句固定话 · 照录）

1. **通常多久**：按合同结算周期；需对账按对账节奏（**待运维核定**）；
2. **同步还是异步**：异步，以**结算单版本**为准；
3. **超时怎么办**：书面催告并留痕，不得不视为放弃。
