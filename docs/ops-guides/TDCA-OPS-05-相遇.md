## 一、这一步在做什么

**在信息与制度都公开的前提下，双方自然对上眼。** 相遇是**免费**的、**双向奔赴**的匹配事件 —— **不是「撮合」**；二者**并列不互推**：不得以「相遇」称呼「撮合」，反之亦然。

⚠️ **硬口径（照录）**：**相遇必有场景** —— 场景是它的定义域，**无场景的相遇不成立**；为某次相遇，可以专门构建场景。

---

## 二、开始前要备齐什么（依流程环节卡 §二）

| 项 | 要求 |
|---|---|
| 场景 | 你在哪个场景里遇见对方（**定义域**，须可指认） |
| 你的公开信息 | 制度与能力说明（对方据以判断） |
| 对方的公开信息 | 同上（你据以判断） |
| 相遇记录 | 只记**发生／未发生**两种状态，同链存证 |
| 后续动作 | 握手 → 交互 → 结算（属后面几环，不在本环节办） |

⚠️ **不收费**：不得设「相遇入口费」「相遇流量计价」「相遇曝光计费」（撮合才收费，且另属一条线）。

## 三、按序怎么做

| 步 | 动作 | 依据 |
|---|---|---|
| `1` | 打开并确认站内对应的功能入口 | 依本族编写规格 |
| `2` | 确认本次相遇所在**场景**已在册，并能一句话指认 | 流程环节卡 §一／§五 第 `1` 类 |
| `3` | 核对己方公开信息（制度与能力说明）已公开、可读 | 流程环节卡 §二 |
| `4` | 阅读对方公开信息，据以判断是否构成双向意愿 | 流程环节卡 §二／§四 |
| `5` | 记录相遇状态：仅「已发生」或「未发生」，并写明场景 | 流程环节卡 §二／§四 |
| `6` | 相遇记录同链存证，留存可查的存证号 | 流程环节卡 §二／§五 第 `5` 类 |
| `7` | 双方各自可凭该记录进入**握手**（下一环） | 流程环节卡 §四 |
| `8` | 遇「付费加速相遇」一类提法，明确其为**撮合**，收费事项另走撮合线 | 流程环节卡 §五 第 `4` 类 |

## 四、做完自检（依流程环节卡 §四 · 照录两条）

1. **有相遇记录**，状态为「**已发生**」，且**有场景**可指认；
2. 双方均可据该记录**进入握手**（下一环）。

⚠️ 只有「被看到」或「引用分高」，**不算发生**（发现阶段的产出只是线索）。

---

## 五、走不通怎么办（依流程环节卡 §五 · 六类照录）

| # | 现象 | 什么意思 | 怎么办 |
|---|---|---|---|
| `1` | 找不到可遇见的场景 | 未登记场景或无对应场景 | 先确认场景是否在册；确无则申请构建场景 |
| `2` | 一直被看见但从不发生 | 只有曝光，没有双向意愿 | 属**正常状态**；不得记为「已相遇」 |
| `3` | 对方不回应 | 意愿不成立 | 记「未发生」即可；不反复打扰、不施压 |
| `4` | 有人提出「付费加速相遇」 | 属**撮合**，不是相遇 | 明确区分；收费事项另走撮合线 |
| `5` | 相遇记录查不到 | 存证未落或查询路径不对 | 按存证号查；仍无则报运维 |
| `6` | 被要求为「曝光」付钱 | 违规 | 拒绝并报运维（相遇不得计费） |

---

## 六、多久、同步还是异步、超时怎么办（照流程环节卡 §六 三句固定话）

1. **通常多久**：相遇即时；握手看回应（**待运维核定**）；
2. **同步还是异步**：相遇为事件记录（同步落）；握手异步，**以状态为准**；
3. **超时怎么办**：无回应即记未发生，不重复触达；异常报运维。
