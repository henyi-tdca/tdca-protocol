## 一、这一步在做什么

**按准备阶段定下的里程碑真干活，并把「干到哪了」持续记下来。** 履约期最怕两件事：**进度不透明**（到期才发现落后）与**悄悄改范围**（干着干着变成另一件事）。

⚠️ **硬口径（照录）**：**变更走变更，不走口头**——范围、时点、条件的任何变化都要落字并双方确认。

---

## 二、开始前要备齐什么（依流程环节卡 §二）

| 项 | 要求 |
|---|---|
| 里程碑台账 | 每段：开始了没、做完没、卡在哪 |
| 变更记录 | 谁提的、改什么、对价与工期怎么调整、双方是否接受 |
| 进度报告 | 按约定频次给：完成项 ／ 进行项 ／ 风险项 |
| 异常上报 | 可能延误或超范围的，**先报后干** |
| 过程存证 | 关键节点的执行痕迹（可回溯、可核） |

## 三、按序怎么做

| 步 | 动作 | 依据 |
|---|---|---|
| `1` | 打开并确认站内对应的功能入口 | 依本族编写规格 |
| `2` | 按准备阶段的里程碑，建**里程碑台账**（每段状态可一眼看出） | 流程环节卡 §二／§四 |
| `3` | 按约定频次出**进度报告**（完成项、进行项、风险项） | 流程环节卡 §二／§三 |
| `4` | 出现**可能延误或超范围**的 ⟹ **先报后干**，当轮即报 | 流程环节卡 §二／§三／§五 第 `1` 类 |
| `5` | 范围／时点／条件要变的 ⟹ 走**书面变更单**，双方确认后方计入 | 流程环节卡 §一 硬口径／§五 第 `2`、`3` 类 |
| `6` | 交付物以**哈希锁定版本**，作废版本标明 | 流程环节卡 §五 第 `4` 类 |
| `7` | 关键节点留**过程存证**；补不了的如实标「缺失」 | 流程环节卡 §二／§五 第 `7` 类 |
| `8` | 一方消极履约或关键人失联 ⟹ 按**升级路径**处理，仍无响应走争议入口 | 流程环节卡 §五 第 `5`、`6` 类 |

## 四、做完自检（依流程环节卡 §四 · 照录四条）

1. **进度随时可见**：任何人看台账就知道到哪一步；
2. **变更全留痕**：每次变更都有记录与双方确认；
3. **异常早暴露**：风险在变成事故前提出；
4. **交付物可交接**：到交付环时，材料齐、版本清。

---

## 五、走不通怎么办（依流程环节卡 §五 · 七类照录）

| # | 现象 | 什么意思 | 怎么办 |
|---|---|---|---|
| `1` | 期末才说做不完 | 过程不透明 | 按报告频次补齐；重新排期并书面确认 |
| `2` | 范围悄悄变大 | 越界 | 停手，走变更；未确认的增量**不默认计入** |
| `3` | 变更只在群里说 | 无留痕 | 补书面变更单并双方确认 |
| `4` | 交付物版本混乱 | 后续难验 | 以哈希锁定版本，作废版本标明 |
| `5` | 一方消极履约 | 违约风险 | 书面催告并留痕；升级或走争议入口 |
| `6` | 关键人失联 | 履约受阻 | 按准备阶段的升级路径处理；仍无响应走争议 |
| `7` | 过程无存证 | 事后说不清 | 补关键节点存证；无法补的如实标「缺失」 |

---

## 六、多久、同步还是异步、超时怎么办（照流程环节卡 §六 三句固定话）

1. **通常多久**：按合同里程碑；报告频次按约定（**待运维核定**）；
2. **同步还是异步**：异步，以**里程碑台账与进度报告**为准；
3. **超时怎么办**：当轮即报并重排期；**不攒到期末**。
