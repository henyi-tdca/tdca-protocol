## 一、这一步在做什么

**在沙盒里小规模真跑一遍，看这条路到底行不行——而不动真资产。** 试错的产出不是「结论好不好」，而是**一组可复现的事实**：跑了什么、结果如何、哪里不行、要改什么。

⚠️ **硬口径（照录）**：**沙盒内不发生真实资产转移**；一旦发现要动真钱真数据，**停手，回到谈判**。

---

## 二、开始前要备齐什么（依流程环节卡 §二）

| 项 | 要求 |
|---|---|
| 沙盒环境 | 隔离的测试环境（与生产分开，可清空重来） |
| 试验清单 | 要验证的假设、每条的判据（可量化优先） |
| 样本与参数 | 用多少数据、什么规模、跑几轮 |
| 试错记录 | 每轮：输入、过程、输出、异常、结论 |
| 结论与建议 | 可行 ／ 有条件可行（条件是什么）／ 不可行（卡在哪） |

## 三、按序怎么做

| 步 | 动作 | 依据 |
|---|---|---|
| `1` | 打开并确认站内对应的功能入口 | 依本族编写规格 |
| `2` | 确认在**沙盒环境**内作业（与生产分开，可清空重来） | 流程环节卡 §二／§五 第 `1` 类 |
| `3` | 事前写出**试验清单**：每条假设配一条判据（可量化优先） | 流程环节卡 §二／§五 第 `3` 类 |
| `4` | 定**样本与参数**（数据量、规模、轮数）并设预算上限 | 流程环节卡 §二／§五 第 `6` 类 |
| `5` | 逐轮跑，并逐轮记**输入、过程、输出、异常** | 流程环节卡 §二／§四 |
| `6` | 多轮以上再下结论；波动大的如实写区间 | 流程环节卡 §五 第 `5` 类 |
| `7` | 结论写**可行／有条件可行（条件写到项）／不可行（卡在哪）** | 流程环节卡 §二／§四 |
| `8` | 把结论与记录**附入后续签约附件**，作为条件依据 | 流程环节卡 §五 第 `7` 类 |

## 四、做完自检（依流程环节卡 §四 · 照录四条）

1. **可复现**：换人按记录重跑，结论一致；
2. **判据对齐**：每条假设都有对应的判据与结果，不含糊；
3. **异常如实**：失败与限制**照写**，不粉饰；
4. **可交接**：结论能直接支撑「签约还是回谈判」的决策。

---

## 五、走不通怎么办（依流程环节卡 §五 · 七类照录）

| # | 现象 | 什么意思 | 怎么办 |
|---|---|---|---|
| `1` | 直接在正式环境试 | 越界 | **立即停**；恢复环境，改在沙盒重跑 |
| `2` | 只有结论没有过程 | 不可复现 | 补试错记录（输入／参数／输出） |
| `3` | 结果全靠「我觉得」 | 无判据 | 事前定判据；已跑的标「参考」 |
| `4` | 数据用了不该用的 | 合规风险 | 停手，清空样本，换合规样本重来 |
| `5` | 跑一次就下结论 | 偶然性 | 至少多轮；波动大的如实写区间 |
| `6` | 试错成本失控 | 资源耗尽 | 设预算与上限，超限停手上报 |
| `7` | 试错结论与后续签约脱节 | 白跑 | 结论写入签约附件，作为条件依据 |

---

## 六、多久、同步还是异步、超时怎么办（照流程环节卡 §六 三句固定话）

1. **通常多久**：单点当日；多轮联调按跑数（**待运维核定**）；
2. **同步还是异步**：异步，以**试错记录与结论版本**为准；
3. **超时怎么办**：写明卡点与所需资源，**不默认可行**。
