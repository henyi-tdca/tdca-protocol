# 合规与成熟度说明

本页面向两类读者：关心**许可与合规**的人，以及需要判断**现在到哪一步**的人。
全篇只讲事实与边界：**不承诺时间、不承诺结果、不使用"绝对安全"类表述**。

## 一、许可与合规

- **根目录**内容以 **MIT** 许可发布（见 `LICENSE`）。
- 部分子目录含**独立许可**：`core-go/`、`ecoscan/` 等以 **Apache-2.0** 发布（见各目录内 `LICENSE`）。**两者并存，互不改变。**
- 仓库内另有**治理性说明**（如生态非侵略承诺、防御性公开披露，见 `PATENTS.md`）：**属治理承诺，不是许可条款，也不构成使用前提。**
- **分润条款的性质**：分润为**自愿的商业合作约定**。使用本仓库**不产生任何付费义务**；协议层永久免费。若选择与本项目开展增值服务或商业合作，可约定将相关收益的一定比例（默认建议 15%）回馈项目方或其社区基金会。该条**不构成许可条件，也不构成使用前提**。
- **合规取向**：不发币、不公售、不承诺分红；涉及资金与结算的设计仅以法定货币轨道为对象。
- **取依赖建议**：需要联网取依赖时，请走**官方源或机构级镜像**；**不建议使用第三方加速代理**（此类中转过内容，不可全信）。
- 本页**不构成法律意见**；具体条款之争点请以许可原文与专业法律意见为准。

## 二、成熟度与验证信号

### 现在是什么状态

- **总体为「演示态」**：仓库内示例与模板用于演示机制如何运转，**不构成真实执行路径**。
- **真实态依赖外部基础设施**：结算、税务、版权三条真实通道均待外部接入；**时间表受外部条件制约，不承诺日期**。
- 标记为"演示态"的内容**不可直接用于生产**。

### 能证什么 / 不能证什么

- **有证明文件的**：每项绑定对应证明文件，并附模型假设与适用范围。
- **部分证明或未证的**：显式标注为未证——不隐藏、不含糊带过。
- **证明内容的边界**：不得被用来表述"制度层已成立"之类结论；任何场合**不使用"绝对安全"**。
- **范围限制**：现有形式化工作覆盖**抽象模型**，与真实制度结论之间仍有距离——**读者不应高估**。

### 外部采用记录（如实）

- 外部关注度**极低**（星标 0、复刻 1）；
- **无外部议题、无外部贡献**（最近记录皆为项目方自身）；
- 准入记录**均为项目方自身**，**尚无第三方通过准入流程**；
- 结论：**尚无独立第三方在生产场景使用**的记录。

### 适合谁 / 不适合谁

- **适合**：研究与评估、概念验证、制度设计参考、教学与宣讲素材。
- **不适合**：生产环境的真实结算与资金流；需要成熟 SDK 直接集成者。

### 看什么可以判断进展（信号，不是承诺）

1. 出现**非项目方**的独立复现或外部贡献；
2. 出现**首条外部准入记录**；
3. **有证明文件的范围扩大**、未证项减少；
4. 三条真实通道（结算／税务／版权）**任一项接入**。
