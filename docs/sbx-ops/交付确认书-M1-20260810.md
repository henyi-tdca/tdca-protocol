### 2.1 激活系数引擎核心实现

```python
# 三档决策门（SV-1 硬编码，语义对齐任务书 F3 / KB-ECON-001 §7）
if coefficient > 1.2:        # ACTIVATION_THRESHOLD = 1.2 硬编码常量
    status = "财政自给性达成"   # → 政策可复制推广（出盒必要条件，非充分）
elif coefficient > 1.0:
    status = "基本盈亏平衡"     # → 条件续期
else:
    status = "财政不可持续"     # → 负空间熔断 / 资产清算
```

数据性质强制标注：所有输入数据须标注 `data_nature: "real" | "simulated"`（开发纪律 1：激活系数不可 mock，数据性质不可缺省伪造）；出盒前须对接真实 MOU 数据（任务书 §八）。
