## 二、三空间的制度定义

| 空间 | TDCA定位 | 功能 | 状态标识 |
|------|---------|------|---------|
| 负空间审查区 | NSFL 编译器前置闸口 | 对拟进入主体进行负空间函数语言扫描，识别绝对禁止项与场景限制项 | NS-PENDING |
| 沙盒验证区 | Meta-TDCA 生态沙盒 | 在隔离环境中验证主体的正和性、配置权边界声明、函数语料六要素完整性 | SBX-ACTIVE |
| 协议配置市场 | L2 使用权/配置权市场 | 主体获得配置权调度资格，参与跨主体协作，实时接受 MOU 锚定与负空间监控 | PCM-LIVE |

## 三、状态转换的硬条件

### 3.1 负空间审查区 → 沙盒验证区

触发条件：主体提交函数语料六要素 + 负空间声明矩阵

审查内容：
- NS-Type 声明完整性（绝对禁止/场景限制/需审批）
- ⊗禁止操作符覆盖度（是否遗漏法律负空间）
- 法律负空间绝对化检查（刑事/行政禁止领域）
- 最小化合原则验证（是否过度设计）

输出：NSFL-CERT 负空间合规证书（含有效期）

### 3.2 沙盒验证区 → 协议配置市场

触发条件：沙盒内完成规定周期验证 + 激活系数达标

验证内容：
- 正和性验证（效用精灵评估 ERI/CCI）
- 配置权边界压力测试（极端场景下的熔断响应）
- NCA 生成完整性（每次交互是否生成可审计嵌套认知资产）
- 跨域配置权兼容性（与其他主体的函数接口笛卡尔积验证）

核心公式（权威口径，KB-ECON-001 §7 / 任务书 F3）：

```
激活系数 α = (出盒税收贡献 + 就业社保) / 政府初始PCR投入  >  1.2
```

> 修正记录（C1，2026-08-10）：早期稿分子分母颠倒；出盒必要条件为 α > 1.2（财政自给性达成），非 PCR 投入 12 倍于税收。

输出：PCM-ENTRY 协议配置市场准入许可

### 3.3 协议配置市场内的实时审查

监控机制：
- ECE 引擎毫秒级扫描：每次配置权调用前自动执行负空间匹配
- NCA 审计轨迹：每次交互生成嵌套认知资产，供事后追溯
- MOU 实时锚定：连续时间 t 内若 T(y_t) ≤ 0，自动触发效用权重归零（ID79）
- 宪法十六条分布式执行：可观测/正和/自证/负空间熔断

### 3.4 熔断 → 回退 → 休眠/重整

熔断触发条件（任一满足即触发）：
- 触及负空间边界（NSFL Trigger-Block）
- MOU 连续 t 期归零（TDCA-PRINCIPLE-MOU-001 / ID79）
- 正和性验证失败（效用精灵 ERI < 阈值）
- 跨 Agent 消息 NCA 指纹不匹配（AiTM 检测，术语待核）
- 人类最终签名权行使（宪法熔断器）

回退路径：

```
熔断触发
    ↓
立即停止所有配置权调用（快系统，毫秒级）
    ↓
生成熔断 NCA（记录触发原因、上下文、审计轨迹）
    ↓
状态回退至沙盒验证区 `SBX-SUSPENDED`
    ↓
├─→ 轻微越界：沙盒内限期重整，重新验证后可返回 PCM
├─→ 中度越界：沙盒内深度整改，需人类裁决委员会审批
└─→ 严重越界（触及法律负空间）：永久休眠 `SBX-BANNED`，配置权交易价格强制归零
```

## 四、与 TDCA 四层架构的映射

| 三空间循环 | 四层架构 | 制度层级 |
|-----------|---------|---------|
| 负空间审查区 | L0 法律底层 + L1 所有权市场 | 制度基座（不可还原） |
| 沙盒验证区 | L1→L2 过渡带 | 制度-技术动态均衡（ID36，编号待核） |
| 协议配置市场 | L2 使用权/配置权市场 | 制度执行层（技术从属） |
| 实时负空间审查 | L3 效用计量层 | 硬验证层（MOU 锚定） |

## 五、动态性的制度本质

这一循环机制体现了 TDCA 的活制度特征：

- **非一次性准入**：进入协议配置市场不是"终身牌照"，而是有条件的动态授权。每次配置权调用都是一次重新验证。
- **负空间的进化性**：负空间清单不是静态的，支持 OTA 活宪法升级（ID33）。当法律/监管/社会共识变化时，负空间审查标准同步更新，已准入主体必须重新通过增量审查。
- **沙盒的递归性**：沙盒本身也是 TDCA 生态的一部分，可由多个主体共建。一个被熔断回退的主体，可以在沙盒中与其他主体形成"沙盒内的沙盒"，进行更细粒度的验证。
- **MOU 的实时性**：不是"年度审计"，而是每次调用即验证。数字人民币智能合约将"调用即纳税"编码为硬约束，使越界行为在经济上即时不可行。
- **人类介入的保留**：快系统处理 99.9% 的确定性熔断，但慢系统保留最终裁决权（异构三角裁决、宪法 OTA、负空间清单修订）。

## 六、与化学热力学原理簇的深层同构

| 化学概念 | 三空间映射 |
|---------|-----------|
| 五阶资产（化学元素） | 拟进入主体持有的 IP/知识/交换/场景权重/认知 NCA |
| NCA（化合物） | 主体在沙盒中与其他主体化合生成的嵌套认知资产 |
| 活化能 | 负空间审查 + 沙盒验证所需的制度成本 |
| 正向化合（自发放热） | 合规主体进入协议配置市场，释放正和效用剩余 |
| 反向分离（需高活化能） | 熔断回退需法律仲裁/治理介入，成本极高 |
| 偏向性催化剂 | TDCA 协议网络降低正向活化能、提高逆向活化能 |
| NSFL 反应抑制剂 | 阻止非正和方向的化合发生 |

## 七、关键原则重申

- **TDCA-PRINCIPLE-DSA-001-1**：任何主体在协议配置市场中的存在状态不是二元的（准入/拒绝），而是连续的动态光谱——从 NS-PENDING 到 SBX-ACTIVE 到 PCM-LIVE，再到 SBX-SUSPENDED 或 SBX-BANNED，每一步转换都有明确的制度硬条件与可审计轨迹。
- **TDCA-PRINCIPLE-DSA-001-2**：负空间审查不是"审查一次管终身"，而是持续性的制度呼吸——协议配置市场中的每一次心跳（配置权调用）都必须通过负空间的肺泡。
