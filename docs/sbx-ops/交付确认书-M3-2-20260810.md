## 五、核心制度落地

### 5.1 SV-1 必要非充分

```
α > 1.2 仅为准入条件（必要），非出盒充分条件。
出盒还须满足：sandbox_pass / delta_utility 消费沙盒真实评估记录。
拒绝客户端自报（与 M2 surplus 服务端绑定原则一致）。
```

### 5.2 C03 自证

```
sync 服务端核对沙盒真实 phase（real_phase 由路由从沙盒记录读取）。
不一致 → 409 Conflict，触发重新同步。
```

### 5.3 SV-10 双向存证

```
nca_refs 同时包含 sbx 侧 + flow 侧引用（http 模式提取 8001 响应 nca_records）。
跨系统调用双向可追溯。
```
