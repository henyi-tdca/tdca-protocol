## 三、技术要点（E-2 实现发现）

1. **append_event 期望 V2PrepayRecord**（非 dict）——适配器构造 V2PrepayRecord（status=PREPAID/escrow/data_hash/signature）
2. **ledger 内部 Decimal 运算**——amount 传 Decimal(str(...))（tax_ledger:53-54 current + amount）
3. **total_tax_settled 是 property**（非方法）——调用无括号
4. **综合税率** = dispatch 2% + trade_fee 0.75% ≈ 2.75%（E-1 dvp 简化为 2% 单税——差异已标注，真实计税以 MICROTAX compute_taxes 为准）
