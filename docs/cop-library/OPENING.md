## 二、核心机制（三件套）

### 1. 调用即计费 —— 0.01 元/次（暂定）

- 0.01 元 = **摩擦成本**：刚好大于零，过滤无意义请求（防白嫖）；远小于任何商业价值调用，确保"调用即分润"的极低门槛——ID77（被调用的知识才是有价值的知识）的定价落地
- 记账：NCA 存证（每次调用生成调用记录）——模拟态（e-CNY 接入后凭账本转实际结算，**不发币、只做合法结算**）
- 豁免：内部验证 / 沙盒 / 开源社区演示（标注 simulated）

### 2. 化合即分润 —— 15%（默认值）

```
调用库内协议（0.01 元）→ 用户化合生成新协议 → TDCA 认证（六要素/NSFL/公理 6）
→ NCA 确权（原创方=用户）→ 嵌套认知资产入库 → 后续调用 → 15% 分润给原创方（默认）
→ 沿血缘链分层分配（嵌套可叠加，总比例不超 15% 上限）
```

- 这建立了一套**"认知资产的期权分配系统"**——开源社区最大痛点是"原创者无法变现"，TDCA 给每一位思维协议原创者（无论人类还是智能体）一个"未来版税"承诺
- 15% 为默认值；无明确约定时按此执行；协议可自定义（注册时声明）

### 3. 入池即严选 —— 双重约束 + 三要件

**任何进入思维协议库的协议必须携带双重边界**：
- **TDCA 协议（制度边界）**：宪法十六条 / NSFL 负空间（不发币/不越权/不代币化）/ 公理 6（可审计）/ 配置权协议
- **场景协议（场景边界）**：场景画布六要素 + 场景边界声明——协议仅在声明场景内有效

**入库三要件**（缺一不可）：① 六要素函数语料完整 ② 双边界声明 ③ NCA 确权存证（原创方/血缘链/版本）

> 宁可少而精，不可劣而滥——353 个 COP 是严选资产，不是垃圾堆。
