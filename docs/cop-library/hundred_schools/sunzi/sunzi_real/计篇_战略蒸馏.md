# 《孙子兵法·计篇》战略蒸馏（兵学战略研究院 · 思维协议主编译）

本文件是「兵学战略研究院」基于古籍训诂院《计篇_训诂校勘.md》之文本证据，对计篇做的**战略层思维协议蒸馏**。目标：把"战前庙算"提炼为可调用、可审计、可化合的思维原语（COP 主原语），并标定其负空间（NSFL）。

## 一、篇旨
计篇 = 战前庙算（先胜后战）。全文由"五事—七计—诡道"三层构成：先以五事立静态分析维度，再以七计做动态敌我比较，终以诡道转入战术权变。核心命题：**未战而庙算胜者，得算多也；未战而庙算不胜者，得算少也。多算胜，少算不胜，而况于无算乎。**

## 二、主原语（思维协议核）
**`jing_xiao_wu_shi_qi_ji`（经校五事七计 · 庙算）**
- 签名：`庙算(我方态势, 敌方态势) -> 胜负情实 -> 战/不战`
- 步骤：
  1. `经之以五事`：以道/天/地/将/法五维静态度量双方基础条件（纲纪）
  2. `校之以七计`：以"主孰有道/将孰有能/天地孰得/法令孰行/兵众孰强/士卒孰练/赏罚孰明"动态比量敌我七端（比校）
  3. `而索其情`：由维度分析与比较推演，求出胜负情实（求）
  4. `庙算胜则战，不胜则不战`：先为不可胜，而后求胜（决策）
- 前置：文本确证（训诂院定本 + 校记）
- 后置：导出作战企图；若庙算不胜，转入"先为不可胜"蓄势

## 三、决策树
```
庙算(五事七计)
  ├─ 我方得算 > 敌方  → 可战（先胜后战）
  ├─ 势均            → 伐谋/伐交优先，慎战
  └─ 我方得算 < 敌方  → 不战，先为不可胜（蓄势待变）
```

## 四、负空间（NSFL · 不可为边界）
1. **不察而战**：未行五事七计庙算即开战 —— 违"不可不察"。
2. **以诡道为正道**：混淆"政治正道（令民与上同意）"与"用兵权道（诡道）"——二道分属政治/战术两层，不可互替。
3. **庙算未胜而浪战**：得算少/无算仍决战 —— 直接否定篇旨。
4. **五事七计失真**：比较所依信息（道/将/法等）造假或被欺 —— 庙算前提崩塌。
5. **诡道溢出**：权变用于政治正道领域（如欺民、违盟）—— 越出战术负空间。

## 五、与 TDCA 机制化合点（供 compose_general 后续化合）
- **庙算 ≈ 可审计的事前决策依据**：五事七计即"多维能力比对"，与连接器比配 `form_coalition` 的八维互补评估同构；可经 TDCA核心-02（可审计自主决策）化合为「可审计庙算决策」。
- **七计 ≈ 多主体能力比配**：敌我七端比较 = 比配引擎的候选能力评分雏形。
- **诡道 ≈ 负空间内的灵活权变**：诡道必须受"正道"约束，恰合 NSFL 熔断逻辑（权变只在负空间外合法）。
- **庙算胜/不胜 → 战/不战** = 事前风控_gate，与 enforce_entry 准入门同构。
