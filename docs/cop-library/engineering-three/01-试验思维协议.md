# 试验思维协议（Experimental Design Thinking Protocol）

> TDCA 官方核心推荐 · 智能体协作思维协议系列 · 工程三部曲之一
> 来源：《试验设计与分析》（杨德）全体系提炼（对话源：灰度管理思维协议.docx，2026-08-30）
> 编译状态：源协议已定稿，细分思维待编译（见 编译清单-工程三协议系列-2026-08-30.md）

## 一、核心三原则（不可违背）

1. **惟一差异原则**
   任何观察到的效应，必须仅能归因于处理间的差异。除被研究因子外，其他所有条件必须保持完全一致。
2. **误差控制三支柱**

| 支柱 | 作用 | 操作要点 |
|---|---|---|
| 重复 | 估计试验误差、提高精确度 | 区分试验单元、抽样单元、测量单元，避免伪重复 |
| 随机化 | 消除系统偏差、保证统计推断有效性 | 处理分配、试验顺序必须随机 |
| 局部控制 | 降低环境异质性 | 通过区组、拉丁方、裂区等方式划分同质子空间 |

3. **精确度认知**
   精密度（重复间一致性）→ 随机误差控制
   正确度（与真值接近程度）→ 系统误差消除
   精确度（精密度+正确度）→ 试验设计的终极目标

## 二、试验生命周期（四阶段决策）

探索期 → 析因期 → 优化期 → 验证期

| 阶段 | 核心问题 | 推荐设计策略 |
|---|---|---|
| 探索期 | 哪些因子重要？ | 分式因子设计、正交设计、筛选设计 |
| 析因期 | 主效与互作如何？ | 完全因子设计（2^k / 3^k）、随机区组、拉丁方 |
| 优化期 | 最优条件组合在哪？ | 回归设计、响应曲面、配方设计、稳健设计 |
| 验证期 | 结论是否稳健？ | 独立验证试验、信噪比评估、质量损失函数 |

## 三、设计选择决策树

### 3.1 基础结构选择（先回答：试验单元是否同质？）

- 是否存在已知异质性来源？
  - 否 → 完全随机设计（CRD）
  - 是（单一方向）→ 随机区组设计（RCBD）
  - 是（两个方向）→ 拉丁方 / 正交拉丁方设计
  - 处理数 > 区组容量 → 平衡不完全区组设计（BIBD）/ 部分平衡不完全区组设计（PBIBD）

### 3.2 因子数量与试验成本权衡

| 场景 | 设计选择 | 关键思维 |
|---|---|---|
| 因子少、资源充足 | 全因子设计 | 全面评估主效+所有互作 |
| 因子多、筛选阶段 | 分式因子设计 2^(k-p) | 利用混名关系，牺牲高阶互作换取效率 |
| 多因子多水平 | 正交设计 | 正交表安排，表头设计避免主效与低阶互作混杂 |
| 需保留主效但允许区组混杂 | 混杂设计 | 有策略地将高阶互作与区组混杂 |

### 3.3 特殊约束场景

| 约束类型 | 设计类型 | 核心特征 |
|---|---|---|
| 因子实施难度不同 | 裂区设计 | 主区（难实施）+ 副区（易实施），正交裂区、条区设计 |
| 成分比例约束（总和=1） | 配方设计 | 单形格子、单形矩心、Scheffé多项式模型 |
| 时间序列/顺序效应 | 交替设计 / 反转设计 | 处理时期互作模型、顺序效应模型 |
| 空间异质性显著 | 格子设计 | 平方、矩形、立方格子，广义格子设计 |
| 需补充新处理 | 增广设计 | 在已有试验基础上扩展，修饰增广、行列增广 |
| 长期持续试验 | 长期试验设计 | 考虑后续效应、趋向分析、双重交替 |

## 四、数据分析思维框架

### 4.1 分析流程（强制顺序）

数据整理 → 描述统计 → 分布假设 → 方差分解 → 假设检验 → 多重比较 → 模型诊断 → 结论推断

### 4.2 方差分析（ANOVA）核心思维

- 变异分解：总变异 = 处理效应 + 区组效应 + 误差
- 模型选择：固定效应模型（推断特定水平）vs 随机效应模型（推断总体）
- 多重比较控制：Duncan氏新复极差、Dunnett氏测验、Tukey q值、Duncan-Waller MAR

### 4.3 回归与响应优化

- 一次回归正交设计：线性模型快速定位最优区域
- 二次回归旋转设计：响应曲面法（RSM）精确寻优，需关注 γ 选择与 m₀ 选择
- 配方设计建模：轴点拓广单形设计，处理限制成分（上下界约束）

### 4.4 稳健性评估

- 信噪比（S/N Ratio）：综合衡量均值接近目标与变异最小化
- 质量损失函数：
  - 望目特征：目标值最优
  - 望大特征：极大值最优
  - 望小特征：极小值最优

## 五、质量控制与误差修正

### 5.1 事后统计控制

- 协方差分析（ANCOVA）：利用辅助变量校正系统偏差
- 近邻分析：利用空间/时间相关性提高估计精度（差分分析、协方差分析）

### 5.2 常见认知陷阱

| 陷阱 | 识别信号 | 规避方法 |
|---|---|---|
| 伪重复 | 样本量很大但误差自由度很小 | 明确区分试验单元 vs 测量单元 |
| 主效-互作混淆 | 正交表表头设计不当 | 利用交互作用表，避免主效与低阶互作同列 |
| 区组-处理混杂 | 区组效应与处理效应无法分离 | 严格随机化，必要时采用平衡不完全区组 |
| 多重比较谬误 | 事后大量两两比较 | 控制族错误率，使用专用多重比较方法 |
| 过度外推 | 将模型结论扩展到试验范围外 | 明确界定推断空间，建议验证试验 |

## 六、协议执行检查清单

**设计前**
- ☐ 试验目标是筛选、析因还是优化？
- ☐ 响应变量是否可精确量化？
- ☐ 所有因子水平是否在可操作范围内？
- ☐ 是否区分了可控因子与噪声因子？
- ☐ 样本量是否满足统计功效要求？

**设计中**
- ☐ 是否应用了惟一差异原则？
- ☐ 随机化方案是否明确且可执行？
- ☐ 区组划分是否合理且边界清晰？
- ☐ 正交表/混杂方案的表头设计是否经过核验？

**实施后**
- ☐ 数据是否包含异常值？原因是否记录？
- ☐ 模型假设是否验证？（正态性、方差齐性、独立性）
- ☐ 残差图是否显示模型缺陷？
- ☐ 是否进行了多重比较校正？
- ☐ 结论是否标注了置信区间？

**结论后**
- ☐ 是否建议在最优条件附近进行验证试验？
- ☐ 是否评估了结论对噪声因子的稳健性？
- ☐ 是否明确了试验结论的适用范围？
