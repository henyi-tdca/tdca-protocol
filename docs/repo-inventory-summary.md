# TDCA Asset Index — Public Summary

> TDCA（Trusted Digital Collaboration Architecture）— a protocol-layer institution for trustworthy multi-agent collaboration. This index maps the public asset landscape: five layers plus the external feedback loop that makes TDCA a *living institution*.

## The Five Layers

| Layer | Assets | Role |
|---|---|---|
| ① Institutions | `docs/formal-proofs/` · governance docs · `docs/papers/` (CN/EN + empirics E1–E6) | The rules: what is permitted, priced, provable |
| ② Engines | `core-go/` (Go engines + ecosystem radar) · compiler assets under `docs/cognitive-compiler/` | Turning rules into executable semantics |
| ③ Economic Run | settlement / tax-anchoring / NCA-attribution assets | MOU-anchored value flow: tax & ledger signals |
| ④ Runtime | gateway · MCP bridge · adapters · frontend (test-cloud main, gh-pages fallback) | Where collaboration actually runs |
| ⑤ Business lines | sandbox-ops · scenario packages · education (E-EDU) · community playground | Applied domains feeding evidence back |

## The Feedback Loop (Living Institution)

The pipeline is not one-way — external input returns to the institution layer through three channels:

1. **Code layer** — Issues / PRs from external users → institutional revision (change flow) → engines recompiled → re-release
2. **Utility layer** — configuration-right call data (MOU = minimum observable utility floor) aggregated through the settlement chain → below-floor signals trigger institutional circuit-breakers / revision
3. **Cognition layer** — community discussions & proposals → concept registry → human ruling → new institution / new capability

Three channels make TDCA self-correcting: *external input → institutional evolution → re-release of code and papers*.
