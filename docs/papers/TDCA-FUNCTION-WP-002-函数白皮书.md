## 摘要

TDCA（可信数字通信架构）理论体系长期以法律、经济、协议、工程多语言混写。本白皮书 V2.0 以**函数**为唯一第一性原理，将制度层（宪法十六条）、经济层（MOU/Shapley/UPDA）、认知层（九算子/COP）、工程层（效用精灵/EIOS）统一重写为可计算函数体系：

- **本体**：制度 = 定义在主体-资源-场景-时间上的约束函数族（F_TDCA: A×R×S×T→U，C_16 硬约束）；
- **认识**：九大数学能力算子（O_KKT/M_ECM/B_Bayes/S_Top/P_3D/E_Walras/G_Shapley/Ψ_Self/Φ_Cross）构成认知可计算层；
- **生态**：协作 = 函数复合（正和 Δ_U>0 才准入，负和熔断）；
- **价值**：效用 = 时间动力学过程 U(t)，MOU/MCT 税收锚定，UPDA 价格发现；
- **治理**：制度-技术同构 Φ: L_inst→L_tech + 负空间熔断器 + 沙盒宽容；
- **可审计性**（新增公理 6）：任何制度函数 f 必须存在可计算验证器 f⁻（含右逆 g），排除哈希/黑盒不可审计构造。

## 第 1 章 绪论 · 函数作为制度第一性原理

### 1.1 函数元定义

**定义 1.1（函数）** 函数 f 是集合 X 到 Y 的关系 f ⊆ X×Y，满足：∀x∈X，至多一个 y∈Y 使 (x,y)∈f。记 f: X→Y。X 为定义域（输入空间），Y 为值域（输出空间）。

**定义 1.2（制度函数）** 制度函数是定义在制度对象上的函数，其输入为**可观测状态**，输出为**可执行指令或判定**：f: Ω_obs → Ω_dec，其中 Ω_obs 为可观测状态空间，Ω_dec 为决策/指令空间。

> 溯源: 函数隐喻四定律（ID21，TDCA-INDEX 行 29）；函数元定义 f⊆X×Y 与 A 文件（AUTHORITY-REVIEW-001 审查对象）一致。

### 1.2 制度必须为函数的充要性

**定理 1.1（制度函数化充要性）** 制度可执行当且仅当它可表示为函数。

证明（充分性）：若制度为函数 f: X→Y，则对每个输入 x 存在唯一输出 f(x)，执行机构可确定性执行，行为可预测、可审计、可复现。

证明（必要性）：若制度不可表示为函数——即同一输入可产生不同输出——则同一事实在不同主体/时刻产生不同裁决，制度失去确定性（不满足宪法"可观测/可计量"），不可执行。∎

**推论 1.1** 任何不可函数化的制度条款（语义含混、输入不可观测）必须经 DCD 修订或标记为待澄清（对应修订检查项与澄清流程）。

### 1.3 函数隐喻四定律（数学表述）

四定律构成白皮书全篇的骨架（严格数学展开见附录 C）：

**定律 L1（人人皆函数）** 每个主体 a 是函数 Ψ_a: R×K×S→U——输入资源 R、知识 K、场景 S，输出效用 U。
- 溯源: ID21 定律一；注册表 T-001 五维状态向量（S_human/S_agent_*）为 Ψ_a 的状态内化。

**定律 L2（协作即调用）** 协作 = 函数复合：Ψ_B∘Ψ_A(x) = Ψ_B(Ψ_A(x))——主体 A 的输出作为主体 B 的输入。
- 溯源: ID21 定律二；对应 COP 编译器 dispatch 图（compiler/compiler_wiring.py）。

**定律 L3（权重看总量）** 权重/贡献由输出与输入总量决定：W = g(Output, Input)——非由身份或谈判位置决定。
- 溯源: ID21 定律三；对应 Shapley 值效率公理（G_Shapley 算子）。

**定律 L4（价值在跨界）** 价值产生于跨域同构：Φ: F_A×F_B→F_Cross——不同域（法律/经济/认知/技术）的函数族经同构映射产生新函数。
- 溯源: ID21 定律四；对应治理同构（第 6 章 Φ: L_inst→L_tech）。

### 1.4 方法论三阶

1. **归零**：清除类比修辞（"如""仿佛"），所有概念回到函数定义；
2. **解构**：将复合制度分解为原子函数（宪法十六条 → C_16 约束函数族）；
3. **重构**：以可计算函数重新合成，验证闭包性（复合仍为合法函数）。

**算例 1.1** 传统表述「配置权是所有权三次递归的用益权」（ERRATA E1）在函数论下重构为：φ: (O,U,C) → Cfg——输入所有权 O、用益权 U、合规约束 C，输出配置权函数 φ；φ 本身为函数，满足 φ(g(φ(x)))=φ(x) 右逆属性（第 2 章展开）。

## 第 2 章 本体论 · 制度基座形式化

### 2.1 总函数 F_TDCA

**定义 2.1（总函数）** F_TDCA: A×R×S×T→U——主体空间 A × 资源空间 R × 场景空间 S × 时间 T 到效用空间 U 的总配置函数。

F_TDCA 的可计算性论证：若 A,R,S,T 均为可数/可枚举离散空间（工程上以有限状态空间近似），F_TDCA 为有限定义域函数，可计算（P2 §四 论证 1）。

### 2.2 宪法约束函数族 C_16

**定义 2.2（宪法约束函数族）** C_16 = {C_1, …, C_16}，每个 C_i: Ω→ℝ，制度状态 x 合法当且仅当 C_i(x) ≤ 0 对全部 i=1..16 成立（硬约束）。

- 形式化完整表达式 + 违反检测算法 O(16×复杂度) + 松弛参数 ε_i（沙盒边界）见附录 A。
- 溯源: 宪法十六条（KB-INST-020 / L0-constitution）；A 文件 §2.2 C_16（AUTHORITY-REVIEW-001 行 16 确认语义对齐）。

**定理 2.1（约束闭包）** 若 f: X→Y 与 g: Y→Z 均满足 C_16 约束（∀x 合法输入→合法输出），则 g∘f 亦满足 C_16。

证明：C_i(f(x))≤0 且 C_i(g(f(x)))≤0 对 ∀i 成立（逐点验证），复合保持合法性。∎

### 2.3 四要素效用分解

**定义 2.3（四要素效用）** U = U_IP^α · U_K^β · U_E^γ · U_S^δ（Cobb-Douglas 型），其中 U_IP 知识产权、U_K 资本、U_E 生态、U_S 场景，α+β+γ+δ=1。

**性质 2.1** 指数和为 1 ⇒ 规模报酬不变 ⇒ 效用可跨主体按贡献分解（为 Shapley 分配提供可加性基础）。

### 2.4 配置权第三极 φ

**定义 2.4（配置权）** φ: O⊕U⊕C → Cfg——配置权为在所有权 O 与用益权 U 之外的第三极，输入合规约束 C，输出配置函数 φ(x)=Cfg(x)（谁在何时以何参数配置何函数）。

- **法律定位**: 用益权的用益权（民法典 323 条基础 + 465 条合同保护），所有权第三次递归（勘误 E1）。
- **隔离机制**: 所有权时间轴 T_O 与配置权时间轴 T_C 正交（T_O⊥T_C）——配置权操作不触发所有权流转（ERRATA E2）。
- **定价**: P_config = W(s)·U_marginal·ERI——场景权重 × 边际效用 × 生态声誉（第 5 章定义 5.5 展开；ERI 为不可替代性 R_irreplaceable 的可计算代理，注册表 T-042）。

**定理 2.2（配置权右逆）** φ 满足 φ(g(φ(x))) = φ(x)——即配置权函数的右逆 g 存在（公理 6 实例化）：对任意配置权输出 φ(x)，存在可计算 g 还原其输入配置 x（审计时验证配置权授予是否合法）。∎（证明框架见附录 E §E.3）

**算例 2.1** 酒店沙盒（ID90 实证，NCA 009~014）：沙盒内配置权 φ 授予运营商（O 酒店所有权不变），时间隔离 T_O⊥T_C 保证沙盒实验不触发所有权转移；P_config 依场景权重 W_scene 定价，沙盒转正后升级为正式配置权。

## 第 3 章 认识论 · 九大数学能力算子

### 3.1 算子族总览

认知层由九个可计算算子构成（完整数学定义与伪代码见附录 B）：

| 算子 | 功能 | 输入→输出 | 溯源 |
|------|------|----------|------|
| O_KKT | KKT 最优化 | (目标函数, 约束)→最优解 | ID 优化理论簇 |
| M_ECM | 误差修正计量 | (时间序列)→均衡修正 | ID 计量簇 |
| B_Bayes | 贝叶斯信念更新 | (先验, 证据)→后验 | ID 认知簇 |
| S_Top | 拓扑识别 | (关系数据)→CW 复形/纤维丛 | ID 拓扑簇 |
| P_3D | 产权三维解析 | (所有权,用益权,配置权)→三维投影 | 第 2 章 φ 的解析算子 |
| E_Walras | UPDA 均衡求解 | (供需)→均衡价格 | UPDA 价格发现 |
| G_Shapley | 合作博弈分配 | (特征函数)→Shapley 值 | 第 5 章权重分解 |
| Ψ_Self | 自我函数化 | (自身状态)→元认知模型 | 第 8 章自我递归 |
| Φ_Cross | 跨域配置同构 | (两域函数族)→同构映射 | 第 6 章治理同构 |

**定理 3.1（算子可计算性）** 九个算子均为多项式时间可实现算法（除 S_Top 持续同调与 G_Shapley 全枚举在精确形态为指数级，工程形态有近似方案）——见 P2 论证 2（附录 E §E.4）。

### 3.2 B_Bayes 与信念动态

**定义 3.2** B_Bayes: P(θ|D) ∝ P(D|θ)·P(θ)——共轭更新下后验解析可算（附录 B §B.3）。

**定理 3.3（信念收敛）** 在满足一致性证据流的条件下，后验分布随证据累积收敛到真值（Bernstein-von Mises 型收敛）。

### 3.3 S_Top 拓扑识别与持续同调

**定义 3.4** S_Top 将协作关系数据提升为 CW 复形，用持续同调提取拓扑不变量（连通分量/环/空洞），识别结构的"形态"而非数值。

**应用**：跨域同构（第 6 章 Φ）等价于拓扑空间的同胚判定——两制度结构同构当且仅当同调不变量一致（附录 C 定理 C.1）。

### 3.4 Ψ_Self 自我函数化

**定义 3.5** Ψ_Self: Ψ_a ↦ m(Ψ_a)——将主体函数自身作为输入，输出其元认知模型（能力边界、偏好、置信度）。元层递归：Ψ_Self(Ψ_Self) 可定义但需收敛性约束（第 8 章不对称对齐）。

**算例 3.1** 智能体在沙盒中执行 Ψ_Self：输出自身可计算能力图谱（哪些函数可计算、哪些不可），据此申请配置权范围——对应 COP 编译器 semantic_layer 的自省能力（compiler/semantic_layer.py）。

## 第 4 章 生态论 · 多主体协作函数复合

### 4.1 主体函数化

**定义 4.1（主体函数）** 自然人/企业/政府/智能体均为函数 Ψ: R×K×S→U，差异仅在定义域约束与可计算性特征（智能体函数可形式化为程序，自然人函数需观测代理）。

### 4.2 协作 = 函数复合

**定义 4.2（协作复合）** 协作 Ψ_B∘Ψ_A 合法当且仅当：

1. **类型匹配**: codomain(Ψ_A) ⊆ domain(Ψ_B)；
2. **正和条件**: Δ_U = U(Ψ_B∘Ψ_A) − [U(Ψ_A) + U(Ψ_B)] > 0（正和才准入）；
3. **负和熔断**: Δ_U ≤ 0 时 NSFL 熔断器拦截（第 6 章）。

**定理 4.1（正和复合链）** 若每个原子协作 Δ_U_i > 0，且复合保持 C_16 约束（定理 2.1），则有限协作链总效用严格递增。

### 4.3 场景效用函数 U_scene

**定义 4.3** U_scene(s) = Σ_c U_CDE(c|s)——场景 s 的总效用为场景内全部 COP 的场景依存效用之和，其中 U_CDE(c|s) = U0(c)·SC(s)·A(c,s)（注册表 T-110：基准效用×场景权重×适配因子）。

- **最小配置单元**: 场景是效用配置的最小单元（场景之外无配置，配置必须锚定场景）。
- **交互量/税收锚定**: 场景交互量度量与 MOU 税收锚定（第 5 章 M∘T=C∘f）。
- **闭环条件**: 场景内闭环（输入-输出-结算闭环）为合法协作前提。

> 溯源: 场景专题 R-SCENE-1~6（FROZEN）全套术语（T-040~T-109）——U_scene 与 U_CDE 为场景专题核心衔接点（T-110）。

### 4.4 套娃递归（嵌套场景）

**定义 4.4** 场景可嵌套：量子层 → OPC → 沙盒 → 跨生态 → NIA-MACM 七元组——外层场景函数以内层场景函数为输入：U_scene^(k) = F(U_scene^(k-1), …)。

**定理 4.2（嵌套收敛）** 嵌套深度 k 的效用函数在正和条件下收敛（Δ_U>0 保证单调有界）。

### 4.5 权重函数 ERI / CCI

**定义 4.5** 场景内主体权重由 ERI（生态声誉指数，T-042 相关）与 CCI（协作可信指数）决定：W_a = h(ERI_a, CCI_a)——权重是声誉与可信的函数，非固定身份属性（定律 L3 生态化）。

**算例 4.1** 教学视频沙盒（五元拓扑验证，NCA 003~008）：H-M/M-L/μ/G/L-L/MOU 六环节函数复合，正和条件逐环节验证，MOU 票总额锚定场景效用——验证 U_scene 闭环条件成立。

## 第 5 章 价值论 · 效用度量时间动力学

### 5.1 效用时间动态

**定义 5.1（效用过程）** U(t) 为连续时间随机过程，满足随机微分方程：

dU(t) = μ(t)dt + σ(t)dW(t)

其中 μ 漂移项（制度摩擦/增益），σ 波动项（场景不确定性），W 标准布朗运动。

**定理 5.1（效用分解可加性）** 在四要素 Cobb-Douglas（α+β+γ+δ=1）下，总效用增量可加分解为四要素贡献之和——为 G_Shapley 分配提供时间维度基础。

### 5.2 税收锚定 MOU / MCT

**定义 5.2（MOU 正和底线）** MOU = 进项+出项票总额 = 场景效用可持续性的最低可见指标（**地板非天花板、维持信号非效用本身**——MOU 本体论正解，记忆 [[tdca-mou-ontology-canon-20260813]]）。

**定义 5.3（货币-宪法-税收同构）** M∘T = C∘f——货币函数 M、税收函数 T、宪法约束 C、制度函数 f 满足：税收执行 = 宪法对制度函数的约束实例化。

**定理 5.2（MOU 锚定单调性）** 正和协作链（定理 4.1）下 MOU 单调不减：MOU(t₂) ≥ MOU(t₁) 对 t₂>t₁ 成立——MOU 为效用可持续性的保守下界估计。

### 5.3 UPDA 价格发现

**定义 5.4（UPDA 均衡）** E_Walras 迭代价格更新直至供需均衡：p* = E_Walras(供需函数族)。拍卖收敛性见 P2 论证 4。

### 5.4 配置价值定价

**定义 5.5（配置权定价）** P_config = W(s)·U_marginal·ERI——场景权重 × 边际效用 × 生态声誉。

**定理 5.3（定价脱钩）** 配置权价格与所有权价格统计不相关：Cov(P_config, P_own) = 0——配置权价格是协作信任的价格（ERRATA E4），效用锚定均值回归。

**算例 5.1** 酒店沙盒定价（ID90）：沙盒内配置权依 W_scene 定价，与酒店所有权价格脱钩；沙盒转正按 P_config 续签——验证定理 5.3 实证。

## 第 6 章 治理论 · 制度-技术同构与动态均衡

### 6.1 制度-技术同构映射 Φ

**定义 6.1（治理同构）** Φ: L_inst → L_tech 将制度层函数族映射到技术层可执行组件：

| 制度层 L_inst | 技术层 L_tech | 同构映射 |
|--------------|--------------|----------|
| 宪法十六条 C_16 | Checker_i 硬约束检查器 | C_i(x)≤0 → checker 断言 |
| 配置权 φ | API 权限 | φ 授权 → token/权限位 |
| UPDA | 求解器 | E_Walras → 均衡求解模块 |
| IADP-TEA | 握手 | 协议握手 → 状态机 |

**定理 6.1（同构保持）** Φ 为函数族同构：制度层复合 Φ(f∘g) = Φ(f)∘Φ(g)——制度组合规则与技术组合规则一一对应，技术执行即制度执行（零解释偏差，第 9 章）。

### 6.2 动态均衡方程

**定义 6.2** dL/dt = α·(Tech_pressure − Stability_reserve)——制度层演化速率 = 技术压力与稳定储备之差的函数。α>0 时技术压力驱动制度演化（OTA 通道）；α<0 时制度加固。

### 6.3 负空间熔断器（NSFL）

**定义 6.3** 熔断器三档：黄灯（预警）/ 红灯（暂停）/ 黑灯（终止+回滚）。
