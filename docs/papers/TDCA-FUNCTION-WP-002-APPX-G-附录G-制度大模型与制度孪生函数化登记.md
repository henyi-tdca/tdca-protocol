## G.1 函数大模型（F_IM，T-119）

> F_IM: A_inst × R → D ∪ {BLOCKED}

以制度公理为底层基座、函数映射为认知范式、可计算可审计为信任来源的模型物种。**函数语料（六要素）**：

| 要素 | 内容 |
|---|---|
| 目标函数 | 将制度公理编译为确定性判定函数（配置权调用 → 合法/非法/熔断三态） |
| 约束矩阵 | 宪法十六条 C_16 + NSFL 负空间 + 公理 6（f⁻ 可审计，T-114） |
| 先验分布 | 函数隐喻四定律（ID21）+ 制度函数化充要性（T-117）+ 函数五可属性（T-116） |
| 配置权边界 | L2 配置权市场层；不触碰 L0 法律底层 |
| 预期分配 | 确定性执行/确权/结算/熔断输出（可计算可审计） |
| 审计轨迹 | NCA 存证链 + MOU 税收锚定（外部验证） |

## G.2 制度孪生（Φ_IT，T-120）

> Φ_IT: L_inst → F_exec

将制度逻辑本身作为孪生对象，函数化编译生成可计算可验证可演化的数字镜像；独立于数字孪生的元概念。**函数语料**：

| 要素 | 内容 |
|---|---|
| 目标函数 | Φ_IT: L_inst→F_exec（制度逻辑 → 可执行函数族） |
| 约束矩阵 | 宪法十六条 + 接口熵=0（制度约束零信息丢失）+ 笛卡尔积验证 |
| 先验分布 | 制度函数化充要性（T-117）+ 治理同构 Φ: L_inst→L_tech（第 6 章） |
| 配置权边界 | L2 配置权市场层；制度文本不篡改（编译=映射） |
| 预期分配 | 可执行制度协议（确权/结算/熔断）+ OTA 活宪法演化 |
| 审计轨迹 | NCA 存证 + MOU 税收锚定 |

## G.3 语料属性分野（T-121）

参数大模型与函数大模型的本质分野在**语料属性**（描述性 vs 规范性），非架构。**函数语料**：
- 目标函数: 判定模型物种归属（描述性/规范性）
- 约束矩阵: 语料封闭性 × 外部锚定性
- 先验分布: 三阶语料演化轴（逻辑 ⊢ / 描述 P / 规范 MOU）
- 配置权边界: L2 ｜ 预期分配: 物种定性（护城河判定）｜ 审计轨迹: NCA 溯源

## G.4 规范性语料（T-122）

封闭的、必然的、规范驱动的语料（制度公理/宪法十六条/NSFL/MOU 公式）；认知范式=必然执行（MOU）；信任来源=外部税收锚定。与"法律文本"区分——已编译的必然执行规则。

## G.5 描述性语料（T-123）

开放的、概率的、经验驱动的语料（自然语言/代码/对话）；认知范式=统计拟合（P）；根本局限=幻觉与不可解释。

## G.6 外部制度锚定（T-124）

将信任验证锚点外迁至制度层的方法论——外部不可伪造制度数据（税收 MOU）破解自指悖论（哥德尔困境）。方法论层；MOU 为机制实例层。对应 TDCA-PRINCIPLE-MOU-001。

## G.7 制度主义范式（T-125）

继符号主义（1956–1993）、统计主义（1993–2025）后的第三范式（制度主义）——制度同构/函数协议化/可信协作拓扑；外部锚定破解哥德尔困境；家国天下文化本源（ID32 制度红利>技术红利）。
