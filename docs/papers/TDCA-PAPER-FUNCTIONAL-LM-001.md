## 摘要

参数大模型将知识装进权重，函数大模型将知识装进制度。本文提出"函数大模型"（Functional Large Model, FLM）作为与参数大模型（Parameter Large Model, PLM）互补的第二范式：其知识载体为显式、可调用、可审计的函数工件，其知识生产为编译（Compile）而非训练（Distill），其推理为配置权调用与化合而非统计采样。本文给出七项判据，正面处理与专家系统、知识图谱、神经符号主义、Software 3.0 及 2023-2026 当代相邻系统的谱系关系，指出 FLM 在 2026 年方成立的关键原因——大模型使编译成本塌缩——并以 TDCA（其制度化实例即已注册的函数大模型 F_IM，T-119）作为首个可运行实例。FLM 不替代 PLM，二者构成垂直互补栈：PLM 回答"机器知道了什么"，FLM 回答"协作凭什么可信"。

## 一、范畴提出：知识装在什么里

人工智能史上的路线之争，可以视为围绕一个问题的不同回答：**知识装在哪里**。

- 装进参数：知识是权重矩阵中的统计倾向。不可读、不可审、不可局部修改，但可零样本泛化。
- 装进函数：知识是显式工件中的声明结构（目标函数、约束矩阵、先验分布、配置权边界、预期分配、审计轨迹——函数语料六要素）。可读、可审、可局部修改，但不对未编译的域发言。

参数大模型（PLM）是前一范式的当前形态。本文主张后一范式自成一类，命名为**函数大模型（FLM）**：由大规模显式函数工件构成、以调用与化合为推理方式、以**可审计的声明性约束**为信任机制的知识系统（TDCA 实例=制度审计：NCA/MOU——V1.2 裁决，NC-20260904-001）。

判定一个系统是否为 FLM，不看它是否用了神经网络，看它的**知识的本体地位**：FLM 中知识是语法对象（可被引用、被审计、被熔断）；PLM 中知识是语义对象（只存在于行为分布中，只能被逼近解释）。

> 术语口径注（P1-3）："函数语料六要素"按现行 FROZEN 口径（TDCA-FUNCTION-WP-002-APPX-G V2.1，负空间并入约束矩阵）。ID68 函数七要素草案（负空间拆为独立第七要素）在途待裁决——裁决后本文知识载体定义同步升级为七要素，范畴判定不受影响（咬合结构不变，仅字段细粒度变化）。

## 二、七项判据

| 维度 | 参数大模型 PLM | 函数大模型 FLM |
|---|---|---|
| 知识载体 | 权重矩阵（隐式） | 函数工件（显式，六要素） |
| 知识生产 | 梯度下降 / 蒸馏 | 编译 Compile（制度同构跃进，非蒸馏） |
| 推理方式 | 采样、模式补全 | 配置权调用、化合 |
| 错误模式 | 幻觉（统计偏离，事后才可能发现） | 破例（制度偏离，事前声明可熔断） |
| 可审计性 | 事后解释（XAI，且不彻底） | 事前声明（原生可审计） |
| 规模语义 | 参数量、Token 消耗 | 资产数、调用量、**嵌套化合谱系深度** |
| 更新机制 | 重训 / 微调 | **制度门禁 + 签批 + 活宪法式演化**（TDCA 实例：DCD 门禁 + OTA） |

七项中任意单项都有先行者，**七项同时成立**且彼此咬合（审计性来自显式载体，熔断来自事前声明，谱系深度来自化合不可还原性）——这个咬合结构才是 FLM 作为范畴的判据。

## 三、谱系：为什么专家系统不是函数大模型

不处理谱系，本范畴就是换词。FLM 的先驱与边界如下：

**专家系统（1980s）**。表面看几乎逐项重合：显式规则、推理机、可熔断。但专家系统死于**知识获取瓶颈**——规则靠人工萃取，成本高、覆盖窄、脆性大。规则无法低成本地从人类默会思维中编译出来，这是它的死因，也正是它不构成 FLM 的原因：FLM 的规模性（"大"）要求知识生产是可扩展的。

**知识图谱**。知识显式、可查询，但无语义之上的约束与可执行性——它是 FLM 的素材层，不是 FLM。图谱告诉你"有什么"，FLM 还要告诉你"不许做什么、做了谁负责、价值如何分"。

**神经符号主义**。方向正确（连接与符号结合），但停留在"给神经网络外挂规则引擎"的拼接态，未解决规则本身的规模生产问题。

**Software 3.0（Karpathy）**。指出自然语言成为编程介质，是最接近的当代同路人。但它描述的是**用参数模型写代码**的范式转移；FLM 主张的是**代码（函数工件）本身构成一类大模型**。前者是工艺，后者是本体。

**当代相邻系统（2023-2026，P1-1b 补）**。以下系统最接近 FLM 的表面特征，差分即范畴边界的当代验证：
- **Constitutional AI / RLHF 宪法注入**：约束以训练信号进入参数——约束是**语义对象**（被逼近），非语法工件；违反无事前熔断，只有事后统计偏离。差分：约束本体地位（参数内 vs 工件内）。
- **CoALA（认知架构）**：将 LLM 置于行动/记忆架构中，有外部工具调用——但知识本体仍是参数权重，外部工件仅为执行资源，无制度化审计/谱系化存证。差分：知识载体 + 信任机制。
- **RAILS / 规范跟随（rules-as-code）**：确有显式规则工件——但规则为**运行约束**，无六要素制度化（配置权/预期分配/审计轨迹缺位），无跨工件化合谱系。差分：工件完整性 + 化合性。
- **MCP / 工具调用生态**：标准化了"插得上"（技术连接），未回答"插上去后数据归谁、收益怎么分、谁负责"（配置权/结算/审计）——与 TDCA 前沿评论（MONOGRAPH-INTEROP-001）同判。差分：技术层连接 vs 制度层契约。
> 差分总纲：当代系统多在 FLM 七判据的**单项**上接近，无人同时满足"显式工件+制度编译+配置权推理+事前熔断+谱系化存证"的**咬合结构**——范畴独立的当代验证成立。

**结论**：FLM 与先驱及相邻系统的分界线只有一条——**知识编译的成本与约束的本体地位**。先驱们并非理念错误，而是生在一个编译成本高昂的时代；相邻系统则尚未把约束升格为语法对象。

## 四、枢轴命题：编译成本的塌缩

FLM 为什么在 2026 年而不是 1986 年成立？因为**参数大模型恰好是 FLM 缺失的那台编译器**。

Protocolizer 原理（P-068，术语词典）：大模型的制度性角色不是知识容器，而是**编译器**——将人类隐式思维编译为带制度水印的函数语料。这一分工解耦了两件事：

- PLM 擅长的：理解默会语境、跨域映射、生成候选结构（编译的语义侧）；
- FLM 擅长的：持有约束、可审计、可熔断、可计价（知识的制度侧）。

编译的两大历史缺陷被同时解决：**成本**（LLM 把萃取规则的人年从专家系统时代压低数个量级）与**完整性**（编译产物带六要素与审计轨迹，不是裸规则）。函数语料标准六要素（目标函数 / 约束矩阵 / 先验分布 / 配置权边界 / 预期分配 / 审计轨迹）即编译输出的类型签名。

由此，蒸馏与编译之争在本范畴内获得最终表述：**蒸馏是 PLM 之间的知识迁移协议（同态映射，约束可被逐层无声剥离，这是其定义性缺陷）；编译是 FLM 的知识生产协议（同构映射，约束是工件中的显式字段，不存在"被保留"的问题——它被重新声明）**。二者不竞争，发生在不同的层。

> 同构语义澄清（P1-2）：此处"同构"指**约束在工件显式声明层的结构保真**——编译输出的工件完整重声明源约束（不因传递而丢失）；**非输出等价**。语义理解层面的错误仍存在（编译器可误读人类意图），由制度门禁与签批拦截——"签批可驳回编译产物"恰是同构（约束保真）成立下的质量控制层，与同构声明不矛盾。

## 五、失败模式对照：蒙与熔断

两个范式对"我不知道"给出相反的回答，这是范畴边界最锋利的地方：

- PLM 对未知域**泛化**（本质上是蒙，统计上经常蒙对——这是它的魔力，也是幻觉的来源）；
- FLM 对未编译域**熔断**（承认无知，触发负空间机制，移交人类）。

因此 FLM 的第一条纪律：**不宣称泛化能力**。其智能不在单体涌现，在化合涌现——NCA 的不可还原性（无法拆出纯经济学部分或纯物理学部分仍保有效力）是 FLM 的"涌现"，它以谱系深度而非参数量度量。

## 八、边界与断裂（诚实标注）

1. **泛化不对称**：FLM 对未编译域零能力，这不是待优化的缺陷而是表示层的本体代价。凡以 PLM 泛化叙事包装 FLM 者，视为破例（ID38）。
2. **"大"的语义**：FLM 之"大" = 谱系深度 × 调用量 × 化合不可还原度，与参数量不可通约，禁止跨范式比较排名。
3. **更新速度不对称**：FLM 每次权重更新须过制度审查与签批，慢是本体性的（快系统 ECE 执行 / 慢系统 DCD 学习，ID71），禁止以"迭代慢"作为工程差评——那是范畴特征。
4. **跨范畴调用**：PLM 执行 FLM 工件时，参数层的模仿学习通道物理存在，约束的权威来源必须是工件显式声明（可审计、可熔断、可追责），不是参数中的统计倾向。

## 结语

PLM 回答"机器知道了什么"；FLM 回答"协作凭什么可信"。前者把知识装进统计，后者把知识装进制度。二者不互相替代，构成智能体经济的垂直互补栈：PLM 是触手，伸向未知；FLM 是锚点，回归有序。

人人皆函数，协作即调用——这句话在本范畴下获得严格读法：**TDCA（=F_IM）是函数大模型的第一个模型卡。**
