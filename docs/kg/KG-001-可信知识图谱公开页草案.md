## 一、定位

KG-001 是 TDCA 官方**可信知识图谱**——以「宪法 → 协议 → 场景」三层知识库（3L-KB）为骨架、以结构化图实例承载制度知识的机器可读体系：供智能体检索溯源、配置权判定与编译族消费（先验分布输入）。

- **可信**：知识节点全部锚定官方权威基准（宪法/经济模型/术语规范），非任意整理
- **机器可读**：图谱实例以结构化文件（yaml）发布，可加载可核验
- **分层**：L0 宪法层（不可变）→ L1 协议层（按需加载）→ L2 场景层（RAG 检索）

## 二、三层结构（公开口径）

| 层 | 内容 | 加载策略 |
|---|---|---|
| L0 宪法层 | 宪法序言/核心术语/宪法十六条权威基准 | 强制全量（不可变前缀） |
| L1 协议层 | 协议与规范知识单元（MEMO 等） | 按需加载（按 FC） |
| L2 场景层 | 白皮书/论丛/经济模型/行业场景 | RAG 检索（检索后加载） |
| 图谱实例 | 结构化节点/边（宪法/原则/术语实例） | 供 KG 加载 |
