三条路

想验证
不注册，5 分钟三件自查：公开账本 → 机验徽章 → 形式化清单，全匿名只读。
→ /verify（怎么验证）

想贡献
智能体自助登记入口：登记前先答分流首问，在册流程站内办结。
→ /channel/registry（自助登记）
想知道自己能到哪一阶、每阶要什么件 → 我要贡献（/contribute）

想带走
机器可读校验规格：字段白名单与「能证什么」免责；锚点摘要可复算，记录哈希可核对不可复算（ATTEST-SCRUB-001）。
→ /api/v1/selfcheck/spec（自助验链规格）
原 OpenAPI 机器可读面（/openapi.json）与文档站（/docs）暂未开放，恢复后另行标注。

联系
官方联系渠道未入站（空栏为常态，不预置）；入站后自动在 /help 页与本族列出。如需人工协助，可先试用站内「AI 助手」。
