# 快速上手与术语对照（写给第一次来到本仓库的人）

本页只回答两个问题：**怎么跑起来**，以及**文档里那些词是什么意思**。

## 一、五分钟跑起来

**唯一前置**：系统里有 **Python 3.12 或更高**。不装任何第三方依赖。

| # | 想做什么 | 命令 |
|---|---|---|
| 1 | 看一个工具能干什么（建议第一步） | `cd tools && python -m cog_align.cli --help` |
| 2 | 跑一遍双协议引擎测试 | `cd dual && python -m pytest tests/ -q` |
| 3 | 跑增值服务包测试 | `cd tools && python -m pytest value_services -q` |
| 4 | 只读制度包与论文（零依赖） | 直接读 `pack/` 与 `docs/papers/` |

- 第 1 条：**两步、数秒**即可跑通（取出仓库 → 执行命令）。
- 第 2、3 条需要 `pytest`；全新机器多一步（用户级安装即可）：`pip install pytest --user`。
- **四条命令都不需要联网。**

两点提醒：

1. 仓库内**示例与模板均为「演示态」**——用于演示机制如何运转，**不构成真实执行路径**。
2. 若要联网取依赖，请走**官方源或机构级镜像**；**不建议使用第三方加速代理**（我方据实说明：此类中转过内容，不可全信）。

## 二、术语对照

| 术语 | 一句人话 |
|---|---|
| 配置权第三极 | 人、机器、协议三类主体**并列**看待，配置权不归任何一方独有 |
| 协议层免费 | 协议层与基础层不收费；收入来自**调用与调度的计量** |
| 破例识别 | 凡必须"破例"才能成立的说法，本身就是伪创新信号 |
| 协作停机定理 | 协作不是无限迭代：收敛到"正和交付的充分解"即可，越界即熔断停机 |
| 多角色兼容性 | 同一主体在不同场景持多重角色时，须场景隔离、独立审计、独立演化 |
| 最小配置单元 | 能直接参与配置的最小单元就是"场景" |
| 最小化合原则 | 能在既有体系内复用的，就不另建平行体系 |
| 宪法十六条 | 制度的根本规则集（含条号、标题、正文、效力档、关系、版本），不可被技术组件修改 |

## 三、新人常问

- **"演示态"是什么意思**：示例与数据仅用于演示机制如何运转，一律标注；不能当作真实业务数据。
- **"能证什么"**：见本仓库的合规与成熟度说明，其中如实列出已证与未证。
- **该从哪读起**：先跑通上面第 1 条，再读 `pack/`（制度包）与 `docs/papers/`（论文与证据包）。
