## 摘要

当前 AI 工程把几乎全部力气花在两件事上：一是**调度肌肉**（Skill、工具调用、Agent 编排），二是**存储知识**（知识库、RAG、向量库）。这两类能力都至关重要，但它们共同缺失一层——**自主决策的源泉层**：智能体"为何、在何时、以什么原则"去调用能力、去使用知识的那一层。

本白皮书提出并定义 **思维协议（Cognitive Protocol, COP）** 作为这一缺失层的基础设施：它是把人类在不同场景下运用智慧解决问题的方法与原则，编译为智能体可理解、可计算、可审计、可组合的形式。COP 不是知识（存"是什么"），不是 Skill（程序性能力），也不是编排（路由骨架）——它是站在它们之上的**参数流动设计者**与**语义涌现源**。

行业目前无人占位这一上层定义权。本白皮书即主张并占据它。

---

## 1. 问题：行业缺的那一层

今天主流 AI 工程栈的各层，职责与缺口如下：

| 技术层 | 职责 | 本质 | 缺口 |
|---|---|---|---|
| 提示词（Prompt） | 给模型的扁平指令 | 非结构化文本 | 无结构、不可组合、不可审计、随上下文漂移 |
| 工作流（Workflow） | 刚性执行路径 | 写死的 DAG | 路径固定，无法按态势自主分叉 |
| 编排 / Agent 框架 | 路由 who-calls-whom | 调度骨架 | 只管"调谁"，不管"为何、按何原则" |
| 知识库 / RAG | 存储与检索内容 | 静态配置 | 存"是什么"，不存"怎么想" |
| Skill / 工具 | 暴露可调用能力 | 程序性肌肉 | 无判断、无决策、无原则 |

五层共同缺失的，是一个**决策源泉（decision source）**：它决定在给定态势下，应该激活哪条智慧、以什么顺序、在什么决策门下收敛、在什么负空间边界内停止。没有这一层，智能体要么是"黑箱拍板的提示词"，要么是"写死路径的工作流"，出了事找不到责任点，换场景就得重写。

## 2. 认知资产本体论：四类资产的本质区分

COP 的定位，必须先从本体论上和三类"看似同类"的资产划清边界。它们的本质完全不同：

| 资产 | 本质 | 流动态 | 在谱系中的位置 |
|---|---|---|---|
| 大语言模型（LLM） | 参数概率生成 | 无方向的生成基质 | 生成式层 |
| 知识图谱 / 数据库 / 知识库 | 静态配置 | 不流动 | 静态层 |
| Skill / 工具 | 程序性调用 | 可被调度的肌肉 | 程序性层 |
| **思维协议（COP）** | **拓扑流态认知资产 · 参数流动设计者** | **可组合、可涌现的流态** | **顶端设计者层** |

核心判据有三句：

1. **"大语言模型是参数概率生成，思维协议就是如何调度参数流动的设计者。"** LLM 提供无方向的生成能力；COP 决定这股能力往哪流、按什么拓扑流动、在什么决策门下收敛。
2. **知识图谱 / 数据 / Skill 皆只是"流动配置"**。它们是 COP 调度时的原料与工具，而非 COP 本身。
3. **人类思维从古至今不可计算，但其"拓扑流态"可编译。** 任何著作、任何学科、任何人的思维，价值不在内容（那是知识库能存的东西），而在其流态——它如何从一个态势移动到决策、如何组合解释项涌现新意。COP 捕获的正是这种流态，而非思维内容本身。

价值谱系（自下而上升维）：

```
静态配置 → 程序性调用 → 参数概率生成 → 拓扑流态 · 调度设计者（思维协议）
```

## 3. 什么是思维协议（COP）

**定义**：思维协议是把人类在特定场景下运用智慧解决问题的方法与原则，编译为智能体可理解、可计算、可审计、可组合的形式。它是"大脑"，Skill 是"肌肉"。

**结构化 schema**（已落地实现）：

- `soul`：协议身份、战略层（stratum/branch）、核心原则（core）
- `primitives`：思维原语（CP）集合——每个原语是**函数化**的：
  - 函数签名（fn name(args) -> ret）
  - 前置条件（precond）/ 后置条件（postcond）
  - 负空间标记（⊗）——该步失效的边界
  - 执行即发射 NCA（操作即确权）
- `dispatch`：调度图——主原语在绑定步可嵌套调用下游 COP 的原语
- `decision`：决策门——带信号证据的硬判定（如"必败不可战?"），非随机结论
- `negative_space`：负空间约束——继承解释项约束，防止失效场景
- `validation`：校验——可机器验证结构与 ⊗

**与提示词的本质区别**：提示词是扁平文本，随上下文漂移、不可组合、不可审计；COP 是函数化、可调度、可组合、可确权的结构，行为在确定性的状态机上不走样。

## 4. 嵌套系统：语义涌现而非内禀

COP 不是单条查表规则，而是**可组合的可信推理图谱**。

- 任一 COP 可注册为另一 COP 的**解释项（interpretant）**。父计的内涵随之改变，新语义从组合图上**涌现**，而非内禀于单计。
- 范例（已实证）：`围魏救赵` 作为 `走为上` 的解释项 → 走为上的 core 从"势不可为则退，存为根本"涌现为"**以攻为退**——表面全师而退，实为攻敌必救，于敌回援途中完成转移与再部署"。绑定步"全师而退"被注入"攻敌必救"机制。
- 组合 COP 自动**继承解释项的负空间约束**（如敌无必救之处则该计失效），使组合再复杂也可审计、可熔断。

对比：传统规则系统是扁平查表（if 态势 X then 计 Y，写死）；COP 嵌套系统是可微分的可信推理图谱——同一计在不同组合里含义不同，智能体按态势在"计义空间"中做解释项选择，而非死板匹配。

### 4.1 结构-语义分离：中性化与场景立场

**语义 = g(结构, 场景)**——协议封存"去场景的结构"（中性底片），场景是立场赋予装置（显影液）：

- **中性化**：协议只保留可复用的思维结构（stratum + steps），剥离主体立场。「走为上」固化"脱离交战域以保全实力"——在 A 场景（战略转移、为全局取舍）显现为**主动避让**，在 B 场景（实力悬殊、不得不走）显现为**被迫选择**。立场不在协议里，在场景坐标卡里：同一底片，两张不同的显影液。
- **双协议准入**：任何 COP 须与制度核心协议、场景思维协议**共同运用**——制度立场约束"怎么用"（合规/正和/可审计），场景立场定义"在哪用"（语义/方向/效用），缺一不可（单用中性 COP 无约束、不可准入）。
- **场景栈**：嵌套运用 = 场景栈——栈顶条件决定底片显现形态（正面消耗过大→主动避让；对方实力过强→被迫转移）。这是智能体自主决策非标长尾任务的认知底座：以"将中性协议放入特定场景栈"的确定性操作，替代大模型的幻觉式猜测。
- **定调公式**：思维不是被固化，而是被预置为可显影的底片——去场景化保证底片跨显影液复用，场景化保证每次显影有立场，制度化保证显影不越界；语义从来不在结构里内禀，而是结构在场景坐标系中解蔽出的流质形态。

## 5. TDCA 可信底座：让正和涌现，而非强制

COP 解决"自主决策源泉"问题；TDCA 提供让它**可信**的底座：

- **NCA（嵌套认知资产）**：每一次 COP 执行动作都落一条不可篡改的确权记录，全程可追溯、可回滚、可追责。
- **NSFL（负空间熔断器）**：在编码安全、数据完整性、自主修复等边界硬熔断，异常即暂停。
- **MOU（正和效用底线）**：TDCA **支持**场景协作正和博弈，但**不强制**合作。协作正和由智能体带着 COP 去博弈、去机制设计、去以牙还牙**协商涌现**；协议只把"共赢"变为可审计、可追责的默认解。

这意味着 COP 还有第三个用途维度：**算力的搜索比配调度器**。在多主体协作中，COP 驱动算力全网搜索候选、互补比配、撮合联盟——搜索给候选排序，思维协议比配做出更优撮合（实证中搜索排名第 1 的主体因互补性被否决）。

## 6. 与三类"看似同类"技术的边界（定义权核心）

本节是白皮书的对外主张核心——明确划界，占据上层定义。

### 6.1 COP ≠ 知识库 / RAG
- 知识库存"是什么"（facts、文档、向量）；COP 存"怎么想"（思维的拓扑流态）。
- RAG 检索内容喂给模型；COP 调度模型的参数流动方向。
- 结论：RAG 是 COP 之下的**静态配置层**，二者不可互相替代。

### 6.2 COP ≠ Skill
- Skill 是程序性能力（函数、API、工具），无判断、无原则、无决策。
- COP 是自主决策源泉，决定"为何、何时、以何原则"调用 Skill。
- 结论：Skill 是 COP 之下的**肌肉层**，COP 是调度肌肉的大脑。

### 6.3 COP ≠ 编排 / 工作流 / Agent 框架
- 编排只管路由（who calls whom），工作流写死路径，Agent 框架提供执行骨架。
- COP 提供决策源泉——在路由之上决定"按什么智慧、什么决策门、什么负空间"路由。
- 结论：编排是 COP 之下的**调度骨架**；COP 是赋予骨架以"自主判断"的元层。

**综合声明**：COP 不替代上述任何一层，而是站在它们之上的、行业尚未占位的**自主决策源泉层**。TDCA 的可信底座（NCA/NSFL/MOU）使这一层可审计、可熔断、可正和涌现。

## 8. 行业定义权主张

当前行业在三个方向各有人占位：知识管理（RAG/知识图谱）、能力调度（Skill/Agent 编排）、生成基座（LLM）。**"自主决策的源泉层"——把人类智慧编译为可组合、可审计、可涌现的推理图谱——无人系统定义**。

TDCA 的占位逻辑：

1. 用**函数化原语 + 决策门 + 负空间**把"人类智慧"从口诀/提示词升级为可计算结构；
2. 用**嵌套组合 + 解释项**让语义可涌现、可演化，而非查表；
3. 用 **NCA/NSFL/MOU** 让自主决策可审计、可熔断、可正和涌现；
4. 用**跨范式范式库**（兵法/咨询/博弈论/…可无限扩充）证明该层是通用基础设施，而非某场景特例。

这即是本白皮书主张并占据的上层定义权。
