## 〇、一句话确立

**TDCA 配置权市场确立 C 端（个人消费者）正式参与机制——「消费贡献参与 CCA」**：消费者以真实消费核销产生可验证贡献值，以**需求侧参与权**（观察/投票/让利回馈，等级化可升级）进入配置权市场——**非代币、不可交易、无升值承诺**；制度设计（类型学/定价/结算）+ 三方闭环沙盒实证（26 周模拟）全链闭环。

## 一、机制确立（为什么需要 C 端参与）

TDCA L2 配置权市场原参与者为缔约智能体/组织，**C 端个人消费者无参与通道**——真实消费需求未进入配置权市场需求侧，而 L2 定价 P_C 的 MOU（效用可观测）恰需真实需求信号。**确立通道**：让消费需求以「可验证信号」而非「可交易物」进入市场。

## 二、CCA 参与机制（四步闭环）

```
① 消费核销（real）: C 端到店真实消费 → 权益核销 → 商家流水 NCA 存证
② 贡献值记账:     消费贡献值 = f(消费金额, 核销真实性, 场景) → 消费者贡献账户（NCA 链）
③ 需求信号聚合:   场景级需求信号 D_scene = Σ(贡献值 × 场景权重) → 上链可核
④ 配置市场响应:   智能体/商家按 D_scene 生产配置（调度税模拟态）→ 消费者获让利/贡献等级回馈
```

**参与权设计（不发行可交易物）**：
- **资格**：贡献值达场景阈值 → 该场景需求方观察/投票权（非交易权）——**等级化可升级**（观察/投票/回馈等级随真实贡献提升）
- **权重**：场景投票权重 ∝ 贡献值×场景权重（一人一票基准加权防刷；单人年上限）
- **回馈**：贡献等级 → 商家让利叠加 + 生态荣誉（不承诺收益）
- **约束（不可约四条）**：**不可转让 / 不可交易 / 不可兑现现金 / 无升值承诺**

**跨场景折现**：以**场景互认（SMR）**为前提——场景间有互认规则按规则执行（κ≤1 只缩不放）；无互认禁止（fail-closed）。

## 三、制度坐标（多主体统一配置空间）

| 主体对 | 参与形态 | 覆盖 |
|---|---|---|
| 人-人 | 自然人参与权（等级化）非交易权——不开放转售域 | 确立（CCA） |
| 人-组织 | 组织缔约 + CLS B 端（供应链）｜ 双边消费（merchant_loop 不进 CLS） | 既有 + 本确立 |
| 智能体-智能体 | CCP/微交付（机机面原生） | 既有 |
| 混合（智能体-人/组织） | 跨轨授权（1:1/1:N 撮合，N:N 禁）+ 三方闭环实证 | **本确立核心** |

**分层定价**：P_C 内核不变 + λ_pair 主体对完备度系数（机机/组织=1.0 基准；混合 D-person 0.95 / D-org 0.98 定标——M3 实证收敛）；差额入熔断基金。

## 四、实证（沙盒验证）

- **DCA-重塑版沙盒**：merchant_loop（权益发布/核销/ROI）→ 26 周模拟 → **出盒**（核销率 ≥60% 连续 26 周/零穿池/0 违例/激活 >1.2）
- **R-7 混合市场三方闭环**：C 端消费贡献 → 商家权益 → 智能体撮合，26 周 × 3 seed 全达标（激活 ≈2.20；0 金融化/0 信号购买/0 预收滞留违例）
