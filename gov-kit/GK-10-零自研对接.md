# GK-10 · 零自研对接（Reuse-Only Stack）— 研发治理包通用版

> 研发治理包｜ V0.1-PUB｜ 通用可移植版

## 定位

**企业级工程手段全落「调用或配置」，零自研**——「能复用不新建」的最小化原则落地清单。

## 对接清单（需求 → 现成方案）

| 需求 | 现成方案（调用/配置） |
|---|---|
| 语义缓存 | Redis / 云缓存 |
| 数据预处理 | 开源清洗库 |
| 模型路由 | 开源路由 / 场景路由 |
| 轻量分流 | 本地小模型 API |
| 可观测 | Prometheus/Grafana 或云可观测 |
| 发布/灰度 | CI/CD 平台 |
| 容灾 | 多云/故障转移方案 |

## 纪律

1. 覆盖企业级工程手段全需求——无自研项；
2. 现成方案不足 → **升级负责人**（不自行开发）；
3. 对接 = 配置/复用（交付对接说明 + 零自研声明，不产代码或产配置）；
4. 无存证不交付。

## 记录模板

```yaml
stack_item: STACK-{date}-{seq}
need: <需求>
solution: <现成方案>
mode: <调用/配置/复用>
zero_selfbuild: true
record_ref: <存证号>
```

## 边界

- 技术不竞争（跟随成熟方案，不重复造轮子）；
- 现成方案不足即升级，不自行开发。
