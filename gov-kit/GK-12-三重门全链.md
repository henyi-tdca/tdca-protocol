# GK-12 · 三重门全链（Gate Chain）— 研发治理包通用版

> 研发治理包｜ V0.1-PUB｜ 通用可移植版

## 定位

**每次变更过三门（试验→灰度→可靠），全链存证**——收口规范。

## 三重门全链模型

```
变更 → [试验门] → [灰度门] → [可靠性门] → 全量
       证伪记录    分轨记录     失效检查单
```

| 门 | 制度 | 记录 |
|---|---|---|
| 试验门 | 不试验不立项（证伪预判→沙盒→记录→存证） | TRIAL-{date}-{seq}（GK-01） |
| 灰度门 | 不全量直上（比例/观察期/回滚） | CANARY-{date}-{seq}（GK-02） |
| 可靠性门 | 不设计失效模式不上线（三查 9 项） | RELIABILITY-{date}-{seq}（GK-03） |

## 全链存证模板

```yaml
gate_chain: GATECHAIN-{date}-{seq}
change: <变更内容>
gates:
  trial: {status: PASS/FAIL, record_ref: <TRIAL>}
  canary: {status: PASS/ROLLBACK, record_ref: <CANARY>}
  reliability: {status: PASS(8/9+), record_ref: <RELIABILITY>}
verdict: <全量放行/否决/回滚>
record_ref: <全链收口存证>
```

## 应用

- 新能力/变更按模板走三门全链（缺一即不上线）；
- 微创新可走快速通道（证伪+存证，灰度可选——GK-09）。

## 边界

- 人类最终批准权不可绕过；红线无灰度（立即熔断）。
