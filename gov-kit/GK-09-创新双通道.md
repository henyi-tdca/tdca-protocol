# GK-09 · 创新双通道（Innovation Dual-Track）— 研发治理包通用版

> 研发治理包｜ V0.1-PUB｜ 通用可移植版

## 定位

**让「点子→落地」有确定性制度路径**——创新走完整评审，微创新走快速通道；替代负责人逐个判断点子。

## 双通道

| 通道 | 适用 | 流程 |
|---|---|---|
| **创新通道**（完整） | 新能力/架构级变更 | 提案 → 制度评审（最小化+负空间+试验门）→ 灰度门 → 全量 |
| **微创新通道**（快速） | 低风险微调（不触架构/契约/红线） | 证伪记录 + 存证即可（灰度可选） |

## 创新提案模板

```yaml
innovation_id: INNOV-{date}-{seq}
channel: <innovation/micro-innovation>
title: <提案标题>
task_statement: {目标, 约束, 先验, 边界, 分配, 审计}
falsification_prediction: <证伪预判>
minimalism_check: <已有成熟方案？复用/新建>
negative_space_check: <未触/触发（触发即否决）>
risk_tier: <低/中/高>
record_ref: <存证号>
```

## 微创新快速通道

- 适用：仅文案/参数/流程微调 + 不触架构/契约/红线 + 低风险；
- 流程：证伪记录 + 存证即可；
- 边界：触碰架构/契约/红线 → 升级创新通道。

## 边界

- 通道管确定性路径；人类最终批准权不可绕过；
- 红线违例无通道（立即熔断）；制度否决项负责人可复议。
