# GK-01 · 试验门（Research Gate: Trial）— 研发治理包通用版

> 研发治理包（Governance Kit）｜ 版本 V0.1-PUB ｜ 通用可移植版（去内部概念，语义与内部版零漂移）
> 记录存证：可验证存证记录（Record）；模拟态标注保留（数据性质 real/simulated 如实）

## 定位

新能力/新机制立项的**强制第一道门**：任何新能力必须先在隔离沙盒完成「证伪预判 → 试跑 → 记录」方可进入灰度门。**不试验不立项**——替代「凭经验直接上」。

## 流程（四步）

1. **证伪预判**：立项前填核心假设 + 可证伪判据（出现 X 证据即证伪）；
2. **沙盒试跑**：隔离环境试跑，前置校验（合作可行性：各成员收益 ≥ 保留收益，不满足在沙盒内拦截——非事后发现）；
3. **记录**：如实填写试跑数据与结论（证伪/证实/部分证实）；
4. **存证**：试验记录存证（无存证=未试验）→ 通过后进入灰度门。

## 记录模板

```yaml
trial_id: TRIAL-{date}-{seq}
new_capability: <新能力名称>
core_hypothesis: <核心假设，可证伪表述>
falsification_criterion: <出现 X 证据即证伪>
sandbox_scope: <隔离范围/模拟数据>
precheck:
  coalition_feasible: <各成员收益≥保留收益：PASS/FAIL>
  negative_space: <负空间检查：未触/触发>
verdict: <证伪 → 否决或重构｜证实/部分证实 → 进入灰度门>
record_ref: <存证号>
data_provenance: <real / simulated 如实>
```

## 边界

- 试验门管确定性路径；人类最终批准权不可绕过；
- 已有成熟方案（能复用不新建）不强制试验（最小化原则）；
- 触碰负空间规则 → 立即否决，不进入试验。
