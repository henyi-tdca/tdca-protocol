# GK-07 · 运维分级（Ops Triage）— 研发治理包通用版

> 研发治理包｜ V0.1-PUB｜ 通用可移植版

## 定位

**每日自动观察后的标准处置规则**——三级分级处置，替代「负责人每天巡看有没有问题」。

## 三级处置

| 级别 | 触发 | 处置 | 时限 |
|---|---|---|---|
| 🔴 红线违例 | 负空间触发/规则绕过/对外口径越线 | **立即升级负责人**（不自行处置） | 即时 |
| 🟡 功能缺口/待办候选 | 缺口/缺陷/可优化项 | 登记待办/候选池（按优先级排期） | 当日 |
| 🟢 数据漂移/状态变化 | 数值/状态与基线差异 | 复核确认 → 修正或标注 | 当日 |

## 记录模板

```yaml
ops_entry: OPS-{date}-{seq}
source: <自动观察/哨兵/人工巡查>
finding: <观察项 + 实测值>
tier: <🔴/🟡/🟢>
disposition: <升级负责人/登记待办/复核修正>
record_ref: <存证号>
data_provenance: <real/simulated>
```

## 边界

- 🔴 一律升级负责人，不自行发挥；处置不越权（只读有通道、写入无通道）；
- 无存证=未观察/未处置（fail-closed）。
