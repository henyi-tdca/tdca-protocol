# GK-08 · 优化周快照（Weekly Optimization Snapshot）— 研发治理包通用版

> 研发治理包｜ V0.1-PUB｜ 通用可移植版

## 定位

**优化 = 指标说话**：以周为单位生成指标快照与趋势对比，差异自动暴露优化点——替代「凭感觉判断哪里该优化」。

## 指标集（五类核心）

| 指标 | 达标线 |
|---|---|
| 效用锚定率（有效交易占比） | ≥95% |
| 测试健康（全量回归绿） | 100% |
| 双副本一致（哈希对拍） | 100% |
| 存证闭环率（动作全存证） | 100% |
| 生态活跃（趋势，如实记录零值） | 无固定线 |

## 周快照流程

1. **采集**：每周从各观测源采集（复用自动观察 + 测试 + 账本）；
2. **生成**：周快照（值 + 环比 + 差异标注）；
3. **处置**：未达标 → 自动入优化候选池；连续不达标 → 升级人工裁决；
4. **存证**：周快照存证（无存证=未观察）。

## 记录模板

```yaml
weekly_snapshot: WS-{week}-{year}
utility_anchor_rate: <值+环比>
test_green: <值+环比>
dual_consistent: <值+环比>
record_closure_rate: <值+环比>
ecosystem_activity: <趋势>
below_target: <未达标清单 + 优化候选>
record_ref: <存证号>
```

## 边界

- 指标差异暴露优化点，优化动作本身走三重门（试验→灰度→可靠）；
- 生态活跃为趋势指标（如实记录零值，不注水）。
