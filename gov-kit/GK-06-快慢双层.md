# GK-06 · 快慢双层（Fast/Slow Layers）— 研发治理包通用版

> 研发治理包｜ V0.1-PUB｜ 通用可移植版

## 定位

**明确哪些操作自动执行层接管、哪些异常上报人工裁决层**——自动层解决 99.9% 确定性操作，为人工层提供不可辩驳的证据基础。自动层不替代人类最终批准权。

## 自动执行层范围

| 类别 | 自动化操作 |
|---|---|
| 准入 | 成员自检（规则项 + 负空间熔断） |
| 熔断 | 负空间熔断 / 效用归零熔断 |
| 存证 | 记录生成/链式哈希/双副本同步 |
| 观察 | 定期自动观察 + 分级（🔴红线/🟡待办/🟢复核） |
| 校验 | 合作可行性校验（成员收益≥保留收益） |
| 结算 | 服务费自动划转/分流（模拟态） |

## 人工裁决层（异常上报）

| 情形 | 上报 | 接口 |
|---|---|---|
| 🔴 红线违例 | 负责人（最高层） | 即时升级，不自行处置 |
| 自动层连续异常 | 人工裁决 | 自动上报异常 + 证据包 |
| 高风险变更（架构/契约/对外口径） | 人工裁决 | 灰度门高风险档 + 人审 |
| 无规则可依的新场景 | 负责人（裁决固化规则） | 升级 → 裁决 → 入制度库 |

## 接口契约

- 自动层 → 人工层：异常上报必须附证据包（触发记录/指标/存证）；
- 人工层 → 自动层：裁决结果编码为规则/参数回写（形成闭环）。

## 边界

- 自动层不替代人类最终批准权（宪法级：批准权不可自动化绕过）；
- 制度管确定性路径，人类管价值判断。

## 记录模板

```yaml
fastslow: FASTSLOW-{date}-{seq}
auto_handled: <自动层处理项>
escalated: <上报人工项 + 证据包>
human_ruling: <裁决结果/回写规则>
record_ref: <存证号>
```
