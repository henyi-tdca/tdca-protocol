## 使用三步

1. **读总纲**（GK-00）确认包定位与计费；
2. **选制度**（GK-01~12）按其流程执行（三重门贯穿新能力/变更）；
3. **填模板**（templates/ 对应 yaml）生成记录并存证（无存证=未发生）。
