# 核心公理 ID29~ID38（引用指针 + 摘要）

> 层级: L0 核心公理（引用指针）| 关联: tdca-public/principles/ID29-ID38.md
> 权威表述以 L0 宪法层为准；此处为转译摘要，供场景制度同构校验引用。

| ID | 原理 | 核心表述（转译摘要） |
|----|------|---------------------|
| ID29 | 制度基座第一性 | 制度基座不可还原，技术基座是配置对象 |
| ID30 | 制度执行层从属 | 技术无独立价值主张，价值由制度赋予 |
| ID31 | 最简机制设计 | 用最少规则产生最大秩序（奥卡姆剃刀） |
| ID32 | 制度红利大于技术红利 | 制度红利累积性、网络锁定性、不可复制性 |
| ID34 | 东方智慧根基 | 易经"简易"原则：最少规则 → 最大秩序 |
| ID35 | 制度-技术同构 | 制度逻辑与技术实现同构映射，不允许独立于制度的"创新" |
| ID36 | 制度-技术动态均衡 | 技术迭代边界由制度边界划定，双向校准 |
| ID38 | 破例识别 | 要求破例即伪创新信号 |
| ID71 | 快与慢战略 | 快系统 99.9% 确定性自动化，慢系统人类价值裁决，不可绕过 |
| ID77 | 终极商业模式 | 协议层免费 + 资产专用税（禁止"标准授权费"） |
| ID81 | 五元拓扑空间 | Ω=(V,E,T,G,μ)；配置权协议=坐标变换函数，NCA=张量表示 |
| ID82 | 蒸馏批判与跃进原理 | 非蒸馏；制度同构跃进硬约束之一：接口熵=0 |
| ID85/86 | 负空间两层边界 | 人类价值领地（相对）/ 法律禁止领域（绝对） |
| ID90 | 最小化合原则 | 只在必要时化合：不可拆分性 + 涌现价值 + 非线性 |
| ID92 | 模拟态标注 | 模板/模拟产物必须显式标注，不构成真实配置权执行路径 |

> 场景制度同构校验（ID35）要求：场景公理不得与上述任何 ID 冲突。
