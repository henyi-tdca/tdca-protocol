## 四、⭐ 算法规范（任何人可复算）

```
按记录编号升序排列；
叶 = SHA-256( 该记录件之全部字节 )          # 若缺件：叶 = SHA-256("MISSING:{编号}")
逐层两两：SHA-256( 前叶十六进制串 ‖ 后叶十六进制串 )
该层为奇数时，复制末项参与配对；
反复归并至单值 —— 即根哈希；短式 = 根哈希前 16 位大写。
```
