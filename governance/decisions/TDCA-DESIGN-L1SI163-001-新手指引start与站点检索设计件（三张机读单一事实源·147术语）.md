## 二、⭐ 检索（批 `3`）：目录筛 ＋ 术语跳转

### `2.1` 目录筛（筛选器读 `DOC` 表）

| 维 | 取值 | 说明 |
|---|---|---|
| **类** | `条例`／`标准与流程`／`规范与细则`／`模板与表单`／`基本制度` | 计 `21／17／9／5／4` |
| **态** | `生效`／`指引性`／`草案`／`对外候选`／`非制度件`（待辨 `0`） | 计 `27／17／5／4／3`；⭐ **对外候选 ⛔ 显示为「生效」** |
| **步** | `S1`~`S6` | 计 `5／24／17／26／2／3` |
| **关键词** | 命中 `keys`（显示名／件名／类／态／步／`slug`） | 子串匹配，大小写不敏感 |

- 三个筛选器**可叠加**（`AND`），结果实时计数（如「生效 · 条例 · `S2`：`N` 件」）；
- 结果为空时显示「本组合无件」＋「换个条件」提示，⛔ 显示空白页；
- 排序：态（生效→指引性→草案→对外候选→非制度件）→ 类 → 显示名。

### `2.2` 术语跳转（`TERM` 表 · `147` 条）

- **文档内识别**：正文出现 `T-###` 号 ⟹ 生成跳转链接到该术语条目；出现**术语全名**（`name` 精确匹配）⟹ 同样跳转；
- **术语页内检索**：输入框按 `id`／`name`／`short_def` 匹配，返回条目卡（`id`、名称、所属组、定义首句、状态）；
- **反向查**：术语条目卡显示「引用本术语的制度件 `N` 件」（依 `DOC` 表 `keys` 含该术语名或 `T` 号者，可后续批实现，本批**只留接口位**）；
- ⭐ **歧义口径**：同一词多义者（在册先例：`RTN`／`执行体`／`TDID`）**逐条并列显示**、⛔ 合并成一条；`group` 字段用于消歧（例：`T-029` 与 `T-034` 同涉 `RTN`，分组不同）。
