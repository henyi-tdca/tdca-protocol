## 一、⭐ 追加一段（`§9` **区块锚**）

⭐ 审计报告**必载**一段「区块锚」，把报告锚到当时之**最新已签批区块根**：

| 字段 | 必填 | 说明 |
|---|---|---|
| `block_id` | ✅ | 所锚区块编号（如 `TDCA-NCA-GENESIS-20261022-001`） |
| `kind` | ✅ | `GENESIS` ／ `SEAL` |
| `root_sha256` | ✅ | 区块根全长（`64` 位） |
| `root_16` | ✅ | 短式（前 `16` 位大写） |
| `prev_block_hash` | ✅ | 前块根；创世块填 `GENESIS` |
| `coverage` | ✅ | 覆盖区间与件数 |
| `leaves` | ✅ | 叶数与缺件叶数 |
| `recount` | ⭐ **必填** | ⭐ **审计者自行复算之结果**：`PASS` ／ `FAIL`（附差异件数） |
| `recount_algo` | ✅ | 复算所依规范串 |
| `anchor_note` | ✅ | 若报告时点尚无已签批块，填 `NONE（尚无已签批区块）` —— ⛔ 留白、⛔ 编造 |

---

## 二、⭐ 三条填写纪律

| # | 纪律 |
|---|---|
| `1` | ⭐ **必载最新已签批块**：⭐ 报告**生成时点**所见之最新**已签批**区块；⛔ 引未签批块 |
| `2` | ⭐ **必自复算**：⭐ 审计者**自己算**根，⭐ 结果写 `recount`；⛔ 抄报告方给出的根而不算 |
| `3` | ⭐ **不一致即判**：⭐ 若 `recount=FAIL`，⭐ 报告结论 ⛔ 可给 `PASS`（⭐ 须列差异件） |

⭐ 标准自检原 `20` 条**照旧**；⭐ 本追加另设 ⭐ **检查项 `A-4`**（区块锚三项）：
