## 二、⭐ 契约（读侧 · 建议形态）

### 2.1 单条读数之**十字段**

| # | 字段 | 类型 | 规定 |
|---|---|---|---|
| `1` | `metric_id` | `str` | ⭐ 固定四值：`FUSE_EVENTS`／`POSITIVE_SUM`／`MOU_ANCHOR`／`COMPOUND_CHAIN` |
| `2` | `value` | `num｜null` | ⭐ 读数；⭐ **缺数据时必为 `null`**（⛔ `0`） |
| `3` | `unit` | `str` | `count`／`pct`／`ratio` |
| `4` | `basis` | `str` | ⭐ 口径一句（算的是件数还是事件数；⭐ **件 ⛔ 与事件混算**） |
| `5` | `sample` | `int` | ⭐ 分母（样本量） |
| `6` | `as_of` | `str` | ⭐ **带时区**（如 `2026-10-22T01:30:00+08:00`）；无时区即不合规 |
| `7` | `space` | `str` | ⭐ `NS`／`SBX`／`PCM`（⭐ 该读数所属空间） |
| `8` | `source_module` | `[str]` | ⭐ 取值之模块（可多） |
| `9` | `status` | `str` | ⭐ `OK`／⭐ **`OUT-OF-LEDGER-NOT-CONNECTED`**／`PARTIAL` |
| `10` | `note` | `str` | 缺数原因或口径限制（⛔ 留白） |

### 2.2 批量返回

| 项 | 规定 |
|---|---|
| 形态 | ⭐ 四维一包：`{generated_at, pool_ref, dimensions:[…]}` |
| ⭐ `pool_ref` | 该次取数所依据之沙盒池快照哈希（⭐ 锚**生成时点**） |
| 幂等 | 同一 `pool_ref` ＋ 同一口径 ⟹ 同值；⛔ 随机 |
| 只读 | ⭐ **纯读**：⛔ 写库、⛔ 改状态、⛔ 触发熔断 |

| # | 约束 |
|---|---|
| `1` | ⭐ **缺数为 `null` ＋ `status = OUT-OF-LEDGER-NOT-CONNECTED`**；⛔ 回 `0`、⛔ 回估算值、⛔ 回空串 |
