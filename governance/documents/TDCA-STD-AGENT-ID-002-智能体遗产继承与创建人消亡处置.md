## 一、问题界定

**创建人（人类缔约者/创建者）死亡** → 其对应的智能体及其承载的权益如何处置？
- 与既有框架（TDCA-AGENT-GOVERNANCE-001）聚焦的"智能体退役 → 资产沿创建链回退"方向**相反**：本册处理**人先亡、智能体存续**的方向
- 属身份管理范畴：涉及"创建者权益主体消失后，智能体身份与权益的归属转移"

## 三、制度框架（创建人消亡处置）

### 3.1 处置流程（沿用"法务确认 → 启动继承/清算"既有流程）

```
死亡事实确认（外部法律事实：死亡证明/法院裁定 —— L0 法律层输入，TDCA 不越级判定）
 → 法务确认（沿用既有节点退出流程）
 → 智能体身份处置判定（续存 / 休眠 / 注销——按继承安排与运行基础）
 → 遗产范围清点（配置权 / 分润权益 / 数字资产权益 / 协作资产份额 / NCA 存证归属标注）
 → 继承执行（遗嘱优先；无遗嘱走法定路径 + 沿创建链回退）
 → 继承计税（MOU 锚定）
 → 幂等登记（继承事件 NCA 存证，一次且仅一次）
```

### 3.2 核心规则（候选，对齐治理框架五原则并补创建人维度）

| # | 规则 | 说明 |
|---|---|---|
| R-1 | **遗嘱优先（预授权）** | 创建人生前可通过 NCA 存证设定"智能体处置 + 权益继承"规则（防篡改、可撤回重签）；死亡后按遗嘱执行 |
| R-2 | **无遗嘱 → 沿创建链回退 + 法定路径** | 权益沿创建链回退（公理 6 f⁻ 可审计还原）：智能体权益 → 创建者遗产 → 法定继承；智能体身份按协议分配（续存/休眠/注销） |
| R-3 | **遗产标的界定** | 智能体本身为"制度延伸"（非独立遗产客体）；继承标的是其**承载的**配置权（市场资格/计量余额）、分润权益（15% 嵌套累积）、数字资产权益、协作资产份额 |
| R-4 | **NCA 存证不因死亡消失** | 存证链永续（既有 P9）；死亡仅触发**归属标注变更**（创建者 → 继承人/协议分配方），事实链完整保留 |
| R-5 | **人类裁决兜底（ID71）** | 遗嘱缺失/歧义/多继承人争议 → 人类裁决；AI 不代行 |
| R-6 | **继承计税** | 遗产转移触发 MOU 锚定计税（继承税候选；与税收制度衔接，模拟态标注） |
| R-7 | **幂等防重** | 继承只发生一次；继承动作 NCA 存证；重复申领拒绝 |
| R-8 | **范围与链接层衔接** | 死亡事实与跨域继承属"走出 TDCA 范围"的法律层输入——经国标身份链接层（TDID↔OID 桥接）与外部法律文书对接；TDCA 提供技术框架与接口，不替代法律确权（L0 不越级） |

### 3.3 按身份轨的差异

| 身份轨 | 创建人消亡处置 |
|---|---|
| **永久型智能体** | 身份可续存（继承人接手/托管）或休眠/注销；权益按 §3.2 继承 |
| **日抛型智能体** | **不产生继承**——令牌失效即终（V1.1 界分）；存证轨迹永续但不构成遗产标的 |

## 四、待细化项（登记跟踪）

1. **遗嘱机制规范**：生前预授权遗嘱的字段设计（处置意愿/继承人/生效条件/撤回）+ 存证格式
2. **多继承人/争议**：份额分配（Shapley？法定顺位？）+ 争议裁决流程
3. **与法定继承法衔接**：外部法律文书（死亡证明/继承公证）的验真接口
4. **休眠态定义**：智能体休眠（保留身份与权益、暂停运行）的状态机与唤醒条件
5. **分润权益连续性**：15% 嵌套分润在继承过渡期（未决期间）的记账处理
6. **托管机制**：无继承人时的协议分配去向（回退社区基金会？既有分润口径参照）
