## 一、⭐ 一句话

⭐ **一件事要成为制度，须依次过六道判据**：**是不是**制度性文件 → **要不要**人机双版本 → **够不够格**当正式制度（阶梯＋四步）→ **该不该立**（沙盒两段：先审必要性、再验四性）→ **划不划得来**（全 TDCA 经济性）→ **钱从哪来**（制度性收入口径）。⚠️ 六道**任一不过，即不得称正式制度**。

---

## 二、⭐ 判据链（**六判据 · 逐条**）

### 判据 1 — **是不是制度性文件**（`GSEQ-2016`）

| 判为**制度性**（须双版本） | 仅**人读版**（丙类） |
|---|---|
| ⭐ **九类**：原则·章程·规则·规范·条例·纪律·标准·定式·合约（＋宪法·准则·红线·铁律·禁令·制度） | 评估·审查·记录·清单·提案·决议·裁决·裁定·回报·核证·交办·登记·草材料·建议书 |
| ⭐ **且**对**执行事务有硬约束** | 无硬约束或系一次性动作 |

### 判据 2 — **须不须双版本**（`GSEQ-2018`）

| 体裁 | 版本要求 |
|---|---|
| **手册·指引·指南** ＝ 给人看的 | ⛔ **仅人读版** |
| **细则·流程件** ＝ 涉事务执行 | ⭐ **人读版 ＋ 机读版（同批）** |
| 对外发布件 | ⭐ **三件套**：中文人读 ＋ 英文人读 ＋ 机读 |
| ⭐ **补版本前再审一遍** | 三出口：须补／审后免补／改判 |
| ⭐ **语义权威** | **人读版为权威**；⛔ 机读版不得反向改语义 |

### 判据 3 — **够不够格当正式制度**（`GSEQ-2020` ＋ `GSEQ-2022`）

⭐ **条例门槛**：**未成条例者只能算草案或提案**，⛔ 不得转作正式制度文献。
⭐ **四阶阶梯**：**草案 → 提案 → 条例（正式制度）→ 作废/被取代**。
⭐ **转正四步（缺一不成）**：

| 步 | 名称 | 要求 | 证据 |
|---|---|---|---|
| **①** | **过智库** | 由智库研究起草（问题定性／方案／负空间／替代方案） | 智库起草件 |
| **②** | **过研发治理包** | 挂 gov-kit 各闸（试验闸／灰度闸／其余 GK 制度逐条对齐） | 挂门记录 ＋ 闸门结论 |
| **③** | ⭐ **形式化证明 或 可机验断言**（**二者其一**即可） | 证明件，或「断言 ＋ 机验命令 ＋ 预期结果」 | 证明件／机验器／断言清单 |
| **④** | **沙盒验证** | 提交沙盒验证，**通过后出条例** | 沙盒验证记录（通过结论） |

⚠️ **失败规则**：四步缺任一、或证据不可核 ⟹ ⛔ **只能称草案／提案**；⛔ 不得称正式制度；⛔ 不办制度文献手续（不补机读版）。

### 判据 4 — **沙盒验证两段**（`GSEQ-2025`／`2027`）

**4a 必要性审**（先问）
| 问 | 内容 |
|---|---|
| 用途 | 要解决什么 |
| 紧迫性 | 现在办还是缓办 |
| 类型 | ①填补空白 ②打补丁 ③修订 ④增订 |
| 必要与否 | ⭐ **由实际问题裁决**：现有制度**盖不住 ⟹ 必要**；**盖得住 ⟹ 不立**（问题驱动，⛔ 不凭想立就立） |

**4b 四性验证**（再验）
| 性 | 内容 |
|---|---|
| 可靠性 | 机制本身靠得住 |
| 可行性 | 落得下去、可执行 |
| 经济性 | 见判据 5 |
| ⭐ **冲突与效力适用约束** | 与既有制度是否冲突；⭐ **效力按场景层级适用**（同级效力、越级无效） |

### 判据 5 — ⭐ **经济性（全 TDCA 口径）**（`GSEQ-2029`／`2031`）

| 项 | 口径 |
|---|---|
| **边界** | ⭐ **全 TDCA**（⛔ 不缩到单层、单场景族算账） |
| **成本** | ⭐ **算力支出** |
| **收益** | ⭐ **制度效力产生的资产性收入** |
| **硬线** | ⭐ **执行成本不得大于解决（系统）问题的成本** |
| **局部与全局** | ⭐ **局部亏、全局赚，仍算经济**（局部问题用**全局获益**看待） |
| **时间** | ⭐ **不设时间窗**（看**既有运行能否持续**；效用增益是**时间问题**） |
| **有效解决** | ⭐ **覆盖失效范围后，制度性收入恢复或增加** |

### 判据 6 — ⭐ **制度性收入口径（在册定案）**（`GSEQ-2033`）

⭐ **协议层免费 ＋ 资产配置收费**。
⭐ **收入来源**＝**配置权调用与调度的计量**（**资产专用税／配置权调度税**）。
⛔ 不向协议层本身收费；⛔ 不另立新费目。

### 附条（同属判据链）

| 附 | 内容 |
|---|---|
| **附 1 人机双版本** | 规范类**同批**双版本；**人读版为语义权威**（`GSEQ-2011`） |
| **附 2 存量适用** | ⭐ 存量件**不做批量必要性预审**；⭐ 遇「**不能解决系统问题**」时**接题提案**（问题驱动） |
| **附 3 双版本存量补齐** | 按 **三触发**：①该件下次修订同批补 ②**创始人点定** ③对外发布前必补；⭐ **人读版不动、另出机读版**（`GSEQ-2015`） |

## 三、⭐ 一图流（**判据链顺序**）

```
是不是制度性文件？（九类＋硬约束）
   ├─ 否 → 仅人读版，止
   └─ 是 → 要不要双版本？（手册/指引/指南＝仅人读；细则/流程＝双版本）
            └─ 已定双版本 → 够不够格？（四阶阶梯 · 条例门槛）
                 └─ 未成条例 → 走转正四步：智库 → 研发治理包 → 证明或断言 → 沙盒验证
                      └─ 沙盒两段：4a 必要性审（问题驱动）→ 4b 四性（效力按场景层级）
                           └─ 经济性（全 TDCA · 算力支出 vs 资产性收入 · 无时间窗）
                                └─ 制度性收入（协议层免费＋资产配置收费）
                                     └─ ⭐ 出条例（正式制度）
```
