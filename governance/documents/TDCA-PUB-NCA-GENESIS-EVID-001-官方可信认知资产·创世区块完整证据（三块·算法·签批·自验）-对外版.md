## 三、⭐ 生成算法（完整 · 任何人可复算）

```
1  记录按编号升序排列（数值序）
2  叶 = SHA-256( 该记录件之全部字节 )          → 64 位小写十六进制
   若件缺失：叶 = SHA-256( "MISSING:" + 编号十进制 )
   ⚠️ 缺件不跳过（跳过则根随缺件数变动，不同实现即不同根）
3  逐层两两：SHA-256( 前叶十六进制串 ‖ 后叶十六进制串 )
4  该层为奇数时，复制末项参与配对
5  反复归并至单值 —— 即根哈希；短式 = 根哈希前 16 位大写
```

⭐ **规范串**：`merkle-sha256/leaf=sha256(file-bytes)/pair=sha256(hexbytes a + hexbytes b)/odd=dup-last/v1`

⭐ **禁止进入根计算者**：⭐ 时间戳、随机数、节点本地时间（⭐ 否则他人无法复现同一根）。
